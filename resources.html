资源下载

本页面汇集课程所需的全部可下载资源，包括代码工程、数据手册、工具链安装包、实验报告模板等。所有资源均托管在 GitHub 仓库内，可点击直接下载或克隆整个仓库后离线使用。

一、代码工程

所有代码工程位于仓库 /code 目录，按平台与编号组织。每个工程包含 main.c 主程序、platformio.ini（PlatformIO 配置）和 README.md（接线与运行说明）。STC 工程可在 Keil C51 中新建工程后加入 src/main.c；STM32 工程可在 CubeMX 中按 README 描述重新生成各 IDE 工程。

四、实验报告模板

课程要求学生撰写实验报告，统一使用下列模板。模板为 HTML 格式，可直接在浏览器中打开、填写并打印；也可下载后用 Word 打开另存为 docx 格式。

  • 实验报告模板（HTML 在线版）：lab/report-template.html（推荐在线填写后打印为 PDF 提交）
  • 实验报告模板（直接打印空白表）：打开上述 HTML 后不填写任何内容，直接 Ctrl+P 打印即可得到空白实验报告表

实验报告包含以下栏目：姓名、学号、班级、实验日期、实验名称、实验目的、实验内容、实验过程、实验结果与讨论、教师评语。每次实验均需独立完成一份报告。

六、如何克隆与本地预览

推荐使用 Git 克隆整个仓库到本地：

git clone https://github.com/mingyi0818/IntelligentMcuCourse.git
cd IntelligentMcuCourse
# 启动本地静态服务器预览
python -m http.server 8000
# 浏览器访问 http://localhost:8000

或直接下载 ZIP 压缩包：在 GitHub 仓库页面点击 "Code → Download ZIP"。
