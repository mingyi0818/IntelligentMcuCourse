资源下载

本页面汇集课程所需的全部可下载资源，包括代码工程、课件、数据手册、工具链安装包等。所有资源均托管在 GitHub 仓库内，可点击直接下载或克隆整个仓库后离线使用。

一、代码工程

所有代码工程位于仓库 /code 目录，按平台与编号组织。每个工程包含 main.c 主程序、platformio.ini（PlatformIO 配置）和 README.md（接线与运行说明）。STC 工程可在 Keil C51 中新建工程后加入 src/main.c；STM32 工程可在 CubeMX 中按 README 描述重新生成各 IDE 工程。

六、如何克隆与本地预览

推荐使用 Git 克隆整个仓库到本地：

git clone <仓库地址>
cd Intelligent-McuCourse
# 启动本地静态服务器预览
python -m http.server 8000
# 浏览器访问 http://localhost:8000

或直接下载 ZIP 压缩包：在 GitHub 仓库页面点击 "Code → Download ZIP"。
