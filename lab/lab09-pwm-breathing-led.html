实验9 PWM呼吸灯

PWM (Pulse Width Modulation，脉冲宽度调制) 是通过改变脉冲占空比 (Duty Cycle) 来控制平均输出功率的技术。本实验使用 STM32F407 的通用定时器 TIM3 通道 1 (PA6) 输出 PWM，占空比 0-100% 渐变实现 LED 呼吸效果。完整工程源码见 /code/stm32f407/09-pwm-breathing/。

一、实验目的

  • 理解 PWM 原理与占空比、频率、分辨率的关系。
  • 掌握 STM32F407 通用定时器的 PWM 输出模式配置。
  • 实现呼吸灯效果，理解亮度与占空比的非线性关系。
  • 了解 PWM 在电机调速、LED 调光、D/A 输出中的应用。

二、知识点

  • PWM 原理：高电平时间占周期的比例即占空比 $D = t_{high} / T$。平均电压 $V_{avg} = D \times V_{cc}$。占空比 0-100% 对应平均电压 0-Vcc。
  • 频率选择：LED 调光 PWM 频率应高于 100 Hz (避免可见闪烁)，常用 1-10 kHz；电机调速需考虑电机电感，频率 10-20 kHz。
  • 分辨率：占空比调节步数 = ARR + 1。ARR=99 时分辨率 1% (100 级)，ARR=999 时分辨率 0.1% (1000 级)。
  • STM32 PWM 模式：向上计数模式下，CNT < CCR 时输出有效电平，CNT ≥ CCR 时输出无效电平 (PWM 模式 1)。CCR (Capture/Compare Register) 决定占空比。
  • 占空比计算：$D = CCR / (ARR + 1)$。频率 $f = f_{TIM} / ((PSC+1)(ARR+1))$。
  • 呼吸灯非线性：人眼对亮度感知近似对数，线性增加占空比时中段变化快、两端变化慢。应使用 gamma 校正 (查表) 使亮度变化均匀。
  • 视觉暂留与 PWM：高频 PWM 时人眼只感受平均亮度，无法分辨脉冲，故可平滑调光。

五、代码框架

工程 /code/stm32f407/09-pwm-breathing/main.c。TIM3 时钟 84 MHz，PSC=83 (1 MHz)，ARR=999 (1 kHz，分辨率 0.1%)。

#include "stm32f4xx_hal.h"

TIM_HandleTypeDef htim3;

void PWM_Init(void) {
    __HAL_RCC_TIM3_CLK_ENABLE();
    __HAL_RCC_GPIOA_CLK_ENABLE();

    /* PA6 复用为 TIM3_CH1 */
    GPIO_InitTypeDef gpio = {0};
    gpio.Pin = GPIO_PIN_6;
    gpio.Mode = GPIO_MODE_AF_PP;
    gpio.Pull = GPIO_NOPULL;
    gpio.Speed = GPIO_SPEED_FREQ_LOW;
    gpio.Alternate = GPIO_AF2_TIM3;     /* PA6 复用 TIM3 */
    HAL_GPIO_Init(GPIOA, &gpio);

    htim3.Instance = TIM3;
    htim3.Init.Prescaler = 83;          /* 84MHz/84 = 1MHz */
    htim3.Init.Period = 999;            /* 1MHz/1000 = 1kHz */
    htim3.Init.CounterMode = TIM_COUNTERMODE_UP;
    htim3.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
    HAL_TIM_PWM_Init(&htim3);

    /* CH1 PWM 模式 1 */
    TIM_OC_InitTypeDef oc = {0};
    oc.OCMode = TIM_OCMODE_PWM1;        /* CNT<CCR 输出高 */
    oc.Pulse = 0;                       /* 初始占空比 0 */
    oc.OCPolarity = TIM_OCPOLARITY_HIGH;
    oc.OCFastMode = TIM_OCFAST_DISABLE;
    HAL_TIM_PWM_ConfigChannel(&htim3, &oc, TIM_CHANNEL_1);
    HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
}

/* 设置占空比 0-1000 (0.1% 精度) */
void PWM_SetDuty(uint16_t duty) {
    if (duty > 1000) duty = 1000;
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);
}

/* gamma 校正表: 使亮度变化均匀 (人眼对数响应)
   val 0-255 -> 占空比 0-1000 */
uint16_t gamma_table[256];
void Gamma_Table_Init(void) {
    uint16_t i;
    for (i = 0; i < 256; i++) {
        float f = (float)i / 255.0f;
        /* gamma=2.2 校正 */
        float g = powf(f, 2.2f);
        gamma_table[i] = (uint16_t)(g * 1000.0f);
    }
}

int main(void) {
    int16_t brightness = 0;
    int8_t step = 1;

    HAL_Init();
    PWM_Init();
    Gamma_Table_Init();

    while (1) {
        brightness += step;
        if (brightness >= 255) { brightness = 255; step = -1; }
        if (brightness <= 0)   { brightness = 0;   step = 1;  }
        PWM_SetDuty(gamma_table[brightness]);
        HAL_Delay(10);   /* 10ms 步进, 全程约 5 s */
    }
}

六、调试要点

  • 引脚复用：PA6 必须配置为复用推挽 (GPIO_MODE_AF_PP) 并指定 Alternate=GPIO_AF2_TIM3，否则无波形。
  • 占空比范围：CCR 取值 0 到 ARR，超过 ARR 持续高电平 (常亮)，等于 0 持续低。
  • 频率与分辨率权衡：频率高则分辨率低 (ARR 小)，需根据应用取舍。1 kHz + 1000 级适合调光。
  • 呼吸速度：步进延时决定呼吸周期。10 ms × 255 步 × 2 (亮暗) ≈ 5 s 一周期。
  • gamma 校正：未校正时呼吸中段过快、两端停顿；校正后整体均匀。
  • 示波器验证：观察 PA6 波形，确认频率 1 kHz，占空比随 CCR 改变。
