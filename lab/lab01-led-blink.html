实验1 LED闪烁与流水灯

本实验是单片机入门的第一个实验，通过最简单的 LED (Light Emitting Diode，发光二极管) 闪烁与流水灯，掌握 GPIO (General Purpose Input/Output，通用输入输出口) 输出配置与延时函数原理，并在 STC89C52RC 与 STM32F407 双平台之间进行对照。完整工程源码见 /code/stc89c52rc/01-led-blink/ 与 /code/stm32f407/01-hal-led-blink/。

一、实验目的

  • 掌握 STC89C52RC 与 STM32F407 的 GPIO 输出模式配置方法。
  • 理解软件延时原理，能根据时钟频率估算延时时间。
  • 掌握循环移位实现流水灯的方法。
  • 对比 STC 准双向口与 STM32 推挽输出两种 GPIO 结构的差异。
  • 学会使用 Keil C51 与 STM32CubeIDE 进行工程建立、编译与下载。

二、知识点

  • GPIO 输出模式：STC89C52RC 的 P 口为准双向口 (Quasi-bidirectional)，内部弱上拉、强下拉，输出高电平为弱驱动 (约几十微安)，输出低电平为强灌电流 (约 20 mA)；STM32F407 的 GPIO 支持推挽输出 (Push-Pull)、开漏输出 (Open-Drain) 等 8 种模式，推挽输出可对称输出高低电平，驱动能力约 25 mA。
  • 延时原理：软件延时利用 CPU 执行空循环指令消耗时间，精度受编译器优化影响；硬件定时器延时精度高，可产生精确毫秒级中断。本实验先用软件延时。
  • 限流电阻计算：LED 正向压降 $V_f \approx 2.0\text{ V}$ (红光)，工作电流 $I_f \approx 10\text{ mA}$，电源 $V_{cc} = 5\text{ V}$，则限流电阻 $R = \dfrac{V_{cc} - V_f}{I_f} = \dfrac{5 - 2}{0.01} = 300\,\Omega$，取标称值 220 Ω 至 330 Ω。
  • 循环移位：STC C51 提供 _cror_() 与 _crol_() 循环右移/左移函数 (intrins.h)，移出的位回填到另一端，适合流水灯效果。
  • 视觉暂留：LED 闪烁频率高于 50 Hz 时人眼感觉常亮，流水灯切换间隔 100-300 ms 视觉效果最佳。

四、电路连接

STC89C52RC 使用 P2.0-P2.3 驱动 4 个 LED，LED 共阳接法 (阳极接 Vcc，阴极经限流电阻接 IO，IO 输出低电平点亮)；STM32F407 使用 PE0-PE3 驱动另外 4 个 LED，LED 共阴接法 (阴极接 GND，阳极经限流电阻接 IO，IO 输出高电平点亮)。注意两平台点亮电平相反，这正是准双向口与推挽输出的典型应用差异。

五、代码框架

5.1 STC89C52RC 流水灯代码

使用 P2 口驱动，循环左移实现 4 路 LED 流水效果。工程位于 /code/stc89c52rc/01-led-blink/main.c。

#include <reg52.h>
#include <intrins.h>   /* _crol_ 循环左移函数声明 */

/* 定义 LED 控制口 */
#define LED_PORT P2

/* 软件延时函数：约 1 ms @11.0592MHz
   一次循环约消耗 12 个机器周期，机器周期 = 12/11.0592 us */
void delay_ms(unsigned int ms) {
    unsigned int i, j;
    for (i = 0; i < ms; i++) {
        for (j = 0; j < 114; j++) {   /* 经验值，约 1 ms */
            ;   /* 空操作 */
        }
    }
}

void main(void) {
    unsigned char led = 0xFE;   /* 1111 1110, 最低位 LED 先亮 (共阳低有效) */

    while (1) {
        LED_PORT = led;          /* 输出到 P2 口 */
        delay_ms(200);          /* 延时 200 ms */
        led = _crol_(led, 1);   /* 循环左移 1 位, 0xFE -> 0xFD -> ... */
    }
}

5.2 STM32F407 HAL 库流水灯代码

使用 HAL 库 (Hardware Abstraction Layer，硬件抽象层)，PE0-PE3 配置为推挽输出。工程位于 /code/stm32f407/01-hal-led-blink/main.c。

#include "stm32f4xx_hal.h"

/* LED 引脚定义: PE0-PE3 推挽输出, 高电平点亮 (共阴) */
#define LED_PIN_0  GPIO_PIN_0
#define LED_PIN_1  GPIO_PIN_1
#define LED_PIN_2  GPIO_PIN_2
#define LED_PIN_3  GPIO_PIN_3
#define LED_PORT   GPIOE

void LED_GPIO_Init(void) {
    GPIO_InitTypeDef GPIO_InitStruct = {0};
    __HAL_RCC_GPIOE_CLK_ENABLE();            /* 使能 GPIOE 时钟 */

    GPIO_InitStruct.Pin   = LED_PIN_0 | LED_PIN_1 | LED_PIN_2 | LED_PIN_3;
    GPIO_InitStruct.Mode  = GPIO_MODE_OUTPUT_PP;   /* 推挽输出 */
    GPIO_InitStruct.Pull  = GPIO_NOPULL;            /* 无上下拉 */
    GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;    /* 低速足够 */
    HAL_GPIO_Init(LED_PORT, &GPIO_InitStruct);
}

int main(void) {
    uint16_t pins[4] = {LED_PIN_0, LED_PIN_1, LED_PIN_2, LED_PIN_3};
    uint8_t idx = 0;

    HAL_Init();                  /* 初始化 HAL 库 */
    LED_GPIO_Init();             /* 初始化 LED 引脚 */

    while (1) {
        /* 先关闭所有 LED */
        HAL_GPIO_WritePin(LED_PORT, LED_PIN_0 | LED_PIN_1 | LED_PIN_2 | LED_PIN_3, GPIO_PIN_RESET);
        /* 再点亮当前 LED */
        HAL_GPIO_WritePin(LED_PORT, pins[idx], GPIO_PIN_SET);
        HAL_Delay(200);         /* HAL 库毫秒延时, 基于 SysTick */
        idx = (idx + 1) % 4;    /* 索引循环 */
    }
}

六、调试要点

  • LED 极性：长脚为阳极，短脚为阴极；接反不亮。用万用表二极管档可判断。
  • 限流电阻：不可省略，否则电流过大烧毁 LED 与 IO 口。STM32 单口最大 25 mA，4 路同时需注意总功耗。
  • 延时函数精度：软件延时不精确，受中断和编译优化影响；HAL_Delay 基于 SysTick 中断，精度约 1 ms。需要精确延时应使用硬件定时器。
  • 点亮电平：STC 共阳低有效，写 0 点亮；STM32 共阴高有效，写 1 点亮，二者代码逻辑相反。
  • STM32 时钟使能：操作 GPIO 前必须使能对应端口时钟 (__HAL_RCC_GPIOx_CLK_ENABLE())，否则寄存器无响应。
  • 下载方式：STC 通过 USB 转串口使用 stc-isp 软件下载；STM32 通过 ST-Link 使用 SWD 接口下载。

七、思考题

  1. 计算 11.0592 MHz 晶振下 STC89C52RC 的机器周期，并据此估算 delay_ms 函数中内层循环次数应为多少。
  2. STC89C52RC 准双向口输出高电平时驱动能力较弱 (约 50 μA)，这对 LED 亮度有何影响？应如何改进？
  3. 若将流水灯从 4 路 LED 扩展到 8 路，STC 使用 P2 整口，STM32 使用 PE0-PE7，分别需要修改代码中的哪些部分？
  4. 软件延时与硬件定时器延时各有何优缺点？为什么实际工程中推荐使用硬件定时器？
  5. STM32 的推挽输出与开漏输出在驱动 LED 时有何区别？开漏输出为什么必须外接上拉电阻？
