实验4 数码管动态显示

数码管 (Seven-Segment Display) 是嵌入式系统最常用的数字显示器件。本实验使用 4 位共阴动态数码管，掌握段码 (Segment Code) 与位码 (Digit Code) 的概念，理解动态扫描 (Dynamic Scanning) 利用视觉暂留 (Persistence of Vision) 实现多位显示的原理。完整工程源码见 /code/stc89c52rc/04-7seg-dynamic/。

一、实验目的

  • 掌握数码管的段码 (a-g, dp) 与共阴/共阳的区别。
  • 理解动态扫描原理，能计算刷新频率与显示亮度关系。
  • 掌握段选、位选的驱动方法与消影 (Ghosting) 技术。
  • 能实现 4 位数字的稳定动态显示。

二、知识点

  • 数码管结构：8 段 LED (a, b, c, d, e, f, g, dp) 组成 "8." 字形，共阴 (Common Cathode, CC) 公共端接地，段选高电平点亮；共阳 (Common Anode, CA) 公共端接 Vcc，段选低电平点亮。
  • 段码表：数字 0-9、字母 A-F 的段选编码。共阴 "0" 的段码为 0x3F (abcdef 亮，g 灭)。
  • 动态扫描：多位数码管共享段选线，每位独立位选。依次点亮每一位，每次只亮一位，切换速度高于 50 Hz (人眼视觉暂留约 1/24 s) 即可看到稳定显示，无闪烁。
  • 消影：切换位选前先关闭所有段，避免上一位的段码残影串到下一位 (鬼影 Ghosting)。
  • 刷新频率：4 位轮流显示，每位 5 ms，4 位共 20 ms，刷新频率 $f = 1/0.02 = 50\text{ Hz}$。每位占空比 25%，亮度约为静态显示的 1/4。
  • 亮度与限流：动态显示每位平均电流减小，可适当减小限流电阻 (如 100-150 Ω) 提升单次点亮电流，但不可超过段的最大峰值电流。

四、电路连接

段选 a-g, dp 接 P0.0-P0.7 (需外接 10 kΩ 上拉排阻，因 P0 为开漏)；位选 DIG1-DIG4 接 P2.0-P2.3，经 NPN 三极管 (8050) 驱动公共端 (共阴数码管位选为高有效，三极管导通拉低公共端接地)。实际模块常已集成三极管与电阻。

五、代码框架

实现 4 位计数显示 0000-9999。工程 /code/stc89c52rc/04-7seg-dynamic/main.c。

#include <reg52.h>

#define SEG_PORT P0   /* 段选口 */
#define DIG_PORT P2   /* 位选口 */

/* 共阴段码 0-9 */
unsigned char code SEG[] = {
    0x3F, 0x06, 0x5B, 0x4F, 0x66,
    0x6D, 0x7D, 0x07, 0x7F, 0x6F
};

/* 位选码: 从右到左 DIG1-DIG4 (位选高有效经三极管) */
unsigned char code DIG[] = {0x01, 0x02, 0x04, 0x08};

unsigned char disp_buf[4] = {0, 0, 0, 0};   /* 显示缓冲: 个十百千 */

void delay_ms(unsigned int ms) {
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 114; j++) ;
}

/* 动态扫描一次: 4 位轮流显示 */
void Display_Scan(void) {
    unsigned char i;
    for (i = 0; i < 4; i++) {
        SEG_PORT = 0x00;                  /* 1. 消影: 先关段 */
        DIG_PORT = DIG[i];                /* 2. 选位 */
        SEG_PORT = SEG[disp_buf[i]];      /* 3. 送段码 */
        delay_ms(5);                      /* 4. 延时保持 */
        SEG_PORT = 0x00;                  /* 5. 消影 */
    }
}

void main(void) {
    unsigned int counter = 0;
    unsigned int scan_cnt = 0;

    while (1) {
        /* 更新显示缓冲 */
        disp_buf[0] = counter % 10;          /* 个位 */
        disp_buf[1] = (counter / 10) % 10;   /* 十位 */
        disp_buf[2] = (counter / 100) % 10;  /* 百位 */
        disp_buf[3] = (counter / 1000) % 10; /* 千位 */

        Display_Scan();   /* 扫描一次约 20 ms */

        /* 每 50 次扫描计数 +1, 即约 1 s 加 1 */
        scan_cnt++;
        if (scan_cnt >= 50) {
            scan_cnt = 0;
            counter++;
            if (counter > 9999) counter = 0;
        }
    }
}

更稳定的方案是使用定时器中断进行扫描 (见实验5)，主循环只负责更新数据，避免阻塞。

六、调试要点

  • 消影必须：切换位选前一定要先关段 (写 0)，否则会产生鬼影，显示模糊。代码中 "1. 消影" 与 "5. 消影" 两步不可省。
  • 刷新频率：4 位 × 5 ms = 20 ms，刷新频率 50 Hz 刚好临界，建议每位 2-3 ms 提升到 80-100 Hz，显示更稳定。
  • 亮度不均：若各位亮度不一致，多为位选驱动能力不足或限流电阻差异；三极管基极电阻要匹配。
  • 共阴共阳确认：模块标识 "BS" 通常为共阴，"AS" 为共阳。段码与位码逻辑相反，混淆会导致全亮或全灭。
  • P0 口上拉：STC P0 口开漏，必须外接上拉电阻 (10 kΩ 排阻) 才能输出高电平驱动段选。
  • 三极管方向：共阴数码管位选用 NPN (8050)，共阳用 PNP (8550)；接反则不显示。

七、思考题

  1. 动态显示的刷新频率应不低于多少？若低于该值会出现什么现象？
  2. 为什么动态显示的每位亮度约为静态显示的 1/N (N 为位数)？如何提升亮度？
  3. 消影 (消隐) 的作用是什么？如果不做消影会出现什么现象？
  4. 共阴与共阳数码管在段码、位码上有何区别？给出共阳 "5" 的段码。
  5. 若将扫描放在定时器中断中实现，相比主循环扫描有何优势？请描述定时器中断扫描的方案。
