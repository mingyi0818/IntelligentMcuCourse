课程简介

本课程是计算机类、电子信息类、自动化类专业的专业核心课程，面向应用型人才培养定位，以"理论够用、实践为重、工程导向"为原则，系统讲解单片机原理与开发技术。课程采用"按平台分篇递进"的编排方式：先建立计算机与单片机硬件基础理论，再以 STC 8位单片机（兼容 MCS-51）为入门平台掌握 8 位单片机开发全流程，进而在 STM32 上学习 32 位 Cortex-M4 开发与 FreeRTOS 实时操作系统，最后简介多种单片机开发方式（传统烧录器、ESP32+Arduino、开源鸿蒙、MSP430 低功耗单片机）拓宽视野，并通过综合项目融会贯通。

课程贯穿现代工程实践主线：STC 篇使用 STC-ISP + Keil C51 + VS Code + PlatformIO；STM32 篇使用 STM32CubeMX + STM32CubeIDE + Keil MDK + VS Code；并在 VS Code 中引入 TRAE/Copilot/Cursor/WorkBuddy 等 AI 辅助开发工具，让学生掌握行业前沿的高效开发方法。课程共安排32次课(64课时)，覆盖理论讲授、实验操练与项目实战。

本在线教程为静态网页形式，托管于 GitHub，可在线浏览也可下载离线使用，配套提供教学大纲、实验指导书、可下载代码工程与课件资源。
