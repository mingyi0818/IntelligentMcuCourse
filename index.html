课程简介

本课程面向应用型人才培养定位，以"理论够用、实践为重、工程导向"为原则，系统讲解单片机原理与开发技术。课程采用"按平台分篇递进"的编排方式：先建立计算机与单片机硬件基础理论，再以 STC 8 位单片机（兼容 MCS-51）为入门平台掌握 8 位开发全流程，进而在 STM32 上学习 32 位 Cortex-M4 开发与 FreeRTOS 实时操作系统，最后简介 ESP32+Arduino、开源鸿蒙、MSP430 低功耗单片机等多种平台拓宽视野，并通过综合项目融会贯通。

课程贯穿现代工程实践主线，STC 与 STM32 双平台对照教学，并在 VS Code 中引入 TRAE / Copilot / Cursor / WorkBuddy 等 AI 辅助开发工具，让学生掌握行业前沿的高效开发方法。覆盖理论讲授、实验操练与项目实战，配套提供教学大纲、实验指导书、可下载代码工程与课件资源。

本在线教程为静态网页形式，托管于 GitHub，可在线浏览也可下载离线使用。下方的"课程基本信息"卡片汇总了学时、先修课程、开发工具等结构化字段，便于快速查阅。
