第 3 章 单片机硬件基础

学习目标

  • 理解 CPU 的内部组成（ALU、寄存器组、控制器）与工作原理
  • 掌握 RAM、ROM、Flash、EEPROM 等存储器的特性与适用场景
  • 熟悉数据总线、地址总线、控制总线的作用及其在单片机中的实现
  • 掌握时钟电路与复位电路的设计要点，理解上电复位与按键复位的差异
  • 理解单片机最小系统的概念，掌握电源去耦与滤波设计的基本原则

3.1 CPU 结构与工作原理

CPU（Central Processing Unit，中央处理器）是单片机的核心，由算术逻辑单元（ALU，Arithmetic Logic Unit）、寄存器组（Register Set）和控制器（Control Unit）三大部分组成。寄存器是 CPU 内部速度最快的存储单元，控制器负责译码并产生协调各部件工作的时序信号。

3.1.1 算术逻辑单元 ALU

ALU 是 CPU 的运算核心，负责完成加、减、乘、除等算术运算以及与、或、非、异或、移位等逻辑运算。MCS-51 的 ALU 是 8 位的，一次处理一个字节；STM32 的 Cortex-M4 内核则集成了 32 位 ALU 与单精度浮点单元（FPU）。ALU 不直接保存运算结果，而是将结果写入累加器（ACC）或目标寄存器，并将进位、零标志、溢出标志等写入程序状态字（PSW，Program Status Word）。

3.1.2 寄存器组

寄存器是 CPU 内部的高速存储单元，访问速度远高于 RAM。MCS-51 的常用寄存器如下表：

寄存器位数名称作用
ACC8累加器ALU 的主操作数与结果寄存器
B8B 寄存器乘除法辅助寄存器
PSW8程序状态字存放 CY/AC/OV/P 等标志位
PC16程序计数器指向下一条要执行的指令地址
SP8堆栈指针指向栈顶地址，复位默认 0x07
DPTR16数据指针访问片外 RAM/ROM 的地址寄存器
R0~R78通用寄存器组4 组共 32 个，由 PSW.RS1/RS0 选择

3.1.3 控制器

控制器由指令寄存器（IR）、指令译码器（ID）和时序发生器组成。它从程序存储器取指令字节送入 IR，由 ID 译出操作码含义，再由时序发生器产生执行该指令所需的微操作控制信号，统一调度 ALU、寄存器、总线的工作。

3.2 存储器分类

存储器（Memory）按掉电后数据是否保留，可分为易失性（Volatile）和非易失性（Non-Volatile）两类；按访问方式可分为随机存取（RAM）与只读（ROM）两类。单片机中常用的几种存储器对比如下：

类型易失性可写写入方式典型用途单片机示例
SRAM易失是随机读写变量/堆栈STC 256B / STM32 192KB
DRAM易失是随机读写，需刷新大容量主存单片机较少使用
Mask ROM非易失否工厂掩膜大批量固化程序早期 8051
OTP ROM非易失一次烧录器一次性写入量产固化程序STC15 系列
EEPROM非易失是按字节电擦写参数/配置存储STC8 内置 / AT24C02 外挂
Flash非易失是按扇区电擦写程序存储器STC 8KB / STM32 1MB
Flash 与 EEPROM 的关键差别：Flash 按扇区（Page，通常 512B~2KB）擦除、按字写入，密度高、容量大；EEPROM 按字节擦写，灵活但容量小、寿命有限。STC 8位单片机内置 8KB Flash 用作程序存储器，需保存的参数可外挂 AT24C02 EEPROM 或使用 STC 自带的 EEPROM 模拟区。

3.3 总线与 I/O 接口

总线（Bus）是连接 CPU、存储器与外设的公共信息通道，按功能分为三类：

  • 数据总线（Data Bus，DB）：双向传输数据，宽度等于 CPU 字长。MCS-51 为 8 位，STM32 为 32 位。
  • 地址总线（Address Bus，AB）：单向输出地址，宽度决定寻址空间。MCS-51 为 16 位，可寻址 $2^{16}=64$ KB。
  • 控制总线（Control Bus，CB）：传输读/写、中断响应、复位等控制信号。

在 MCS-51 中，P0 口分时复用为低 8 位地址线和 8 位数据线，由 ALE 信号锁存地址；P2 口输出高 8 位地址。这种"总线复用"是 8051 体系的典型特征，也是初学者理解时序图的难点。

3.4 时钟电路与复位电路

3.4.1 时钟电路

时钟是 CPU 执行指令的时间基准。MCS-51 内部有反相放大器，外接石英晶体（Crystal）和两只 20~30 pF 的匹配电容即可形成皮尔斯振荡电路。常用晶振频率为 11.0592 MHz（便于产生标准波特率，如 9600/19200）或 12 MHz（便于定时计算）。STM32 主时钟由外部 HSE 8 MHz 经 PLL 倍频至 168 MHz。

/* STC 时钟相关说明（无寄存器，硬件提供）
   1) XTAL1 接晶振一脚，XTAL2 接另一脚
   2) 两脚各接一只 30pF 瓷片电容到 GND
   3) 11.0592MHz 晶振下机器周期 = 12 / 11.0592us ≈ 1.085us
      12MHz    晶振下机器周期 = 12 / 12    us  = 1us
   4) STM32 则在 system_stm32f4xx.c 中通过 SystemInit() 配置 PLL
*/
#define FOSC 11059200UL
#define T_1MS (65536 - FOSC/12/1000)  /* 1ms 定时初值（方式1）*/

3.4.2 复位电路

复位（Reset）使 CPU 与所有片内外设恢复到初始状态，PC 指向复位向量 0x0000。MCS-51 的 RST 引脚高电平持续时间需大于 2 个机器周期才能可靠复位，工程上常取 10 ms 以上。常用两种复位电路：

  • 上电复位（Power-On Reset）：利用电容充电特性，RST 引脚通过 10 µF 电容接 VCC、10 kΩ 电阻接地。上电瞬间电容两端电压不能突变，RST 为高电平；电容充电完毕后 RST 被电阻拉低，复位结束。
  • 按键复位（Manual Reset）：在 RST 与 VCC 之间并联按键，按下时 VCC 直接加到 RST，强制复位；松开后电容放电完成复位。

3.5 最小系统

单片机最小系统（Minimum System）是指单片机能正常工作所需的最少外围电路，包括四个要素：电源、时钟、复位、程序下载接口。

3.6 电源与去耦设计要点

电源完整性（Power Integrity）是单片机系统能否稳定运行的基础。单片机在执行指令、切换 I/O 状态时会产生瞬态电流，若供电不足会导致时钟抖动、复位误触发、外设读写错误。常用措施：

  • 电源去耦：每个 VCC 引脚就近并联 0.1 µF 陶瓷电容到 GND，滤除高频噪声；电源入口并联 10 µF~100 µF 电解电容，滤除低频纹波。这就是经典的"大小电容并联"组合。
  • 地线处理：模拟地（AGND）与数字地（DGND）单点连接，避免数字开关噪声串入模拟通道。STM32 有独立的 VSSA/VDDA 引脚专为 ADC 服务。
  • 磁珠隔离：在数字电源与模拟电源之间串联磁珠（如 600Ω@100MHz），进一步抑制高频干扰。
  • 稳压器选择：常用 AMS1117-3.3 / AMS1117-5.0 系列 LDO，输出电流 1A 足够单片机系统使用。功耗较大时改用 DC-DC 开关电源（如 MP1584）。

下面的代码演示如何利用单片机内部 ADC 监测自身供电电压，是判断电源健康状态的常见做法（以 STM32 内部 VREFINT 通道为例）：

/* STM32 HAL 库：读取内部参考电压 VREFINT 监测 VDD
   VREFINT 标称值 1.21V（详见芯片数据手册）
   公式：VDD = 1.21V * 4095 / ADC_VREFINT
*/
#include "stm32f4xx_hal.h"

extern ADC_HandleTypeDef hadc1;

float Read_VDD_Voltage(void) {
    uint32_t raw;
    ADC_ChannelConfTypeDef sConfig = {0};

    sConfig.Channel      = ADC_CHANNEL_VREFINT;
    sConfig.Rank         = 1;
    sConfig.SamplingTime = ADC_SAMPLETIME_480CYCLES;
    HAL_ADC_ConfigChannel(&hadc1, &sConfig);

    HAL_ADC_Start(&hadc1);
    if (HAL_ADC_PollForConversion(&hadc1, 10) == HAL_OK) {
        raw = HAL_ADC_GetValue(&hadc1);
    }
    HAL_ADC_Stop(&hadc1);

    /* VDD = 1.21 * 4095 / raw，单位 V */
    return 1.21f * 4095.0f / (float)raw;
}

/* 调用示例：若读数偏离 3.3V 超过 5%，提示电源异常 */
void Check_Power(void) {
    float vdd = Read_VDD_Voltage();
    if (vdd < 3.13f || vdd > 3.47f) {
        /* 触发报警或进入低功耗安全模式 */
        HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_SET);
    }
}

该示例展示了去耦设计、ADC 参考电压与电源监测之间的工程联系：良好的电源去耦是 ADC 读数稳定的前提，而稳定的 ADC 又是判断电源是否健康的关键。

本章小结

  • CPU 由 ALU、寄存器组、控制器三部分组成，寄存器是访问速度最快的存储单元。
  • 存储器分为易失性 RAM（SRAM/DRAM）与非易失性 ROM（Mask ROM、OTP、EEPROM、Flash），单片机程序存储多用 Flash，参数存储多用 EEPROM。
  • 总线分为数据总线、地址总线、控制总线三类；MCS-51 的 P0 口采用地址/数据分时复用，由 ALE 锁存地址。
  • 时钟电路由晶振与匹配电容组成；复位电路分为上电复位与按键复位，复位时间需足够长以保证可靠复位。
  • 最小系统 = 电源 + 时钟 + 复位 + 下载接口，是单片机能运行的最简电路。
  • 电源去耦采用"大电容滤低频 + 小电容滤高频"的组合，模拟地与数字地单点连接。

思考题与习题

  1. 简述 ALU、寄存器组、控制器三者的功能，并说明 PC、SP、DPTR 在 MCS-51 中的作用。
  2. 比较 SRAM、EEPROM、Flash 三种存储器在掉电保持性、写入粒度、读写速度上的差异。
  3. 为什么 STC 的 P0 口要分时复用为地址/数据总线？ALE 信号的作用是什么？
  4. 设计一个 STC 的最小系统原理框图，标注电源、晶振、复位、下载口的关键元件参数。
  5. 在电源去耦设计中，为什么要在每个 VCC 引脚就近并联 0.1 µF 电容？这个电容的取值依据是什么？
  6. 使用 12 MHz 晶振的 MCS-51，1 个机器周期是多少微秒？若要产生 100 ms 定时，方式 1 下的初值应是多少（用十六进制表示）？
