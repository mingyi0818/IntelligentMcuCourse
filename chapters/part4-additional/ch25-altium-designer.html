第 25 章 Altium Designer PCB 设计

学习目标

  • 理解 Altium Designer 在 EDA 行业中的定位、发展历程与主要功能模块
  • 掌握 Altium Designer 的安装、授权与首次运行环境配置流程
  • 掌握原理图设计（元件放置、连线、网络标号、电源端口）与 PCB 设计（布局、布线、铺铜）的完整流程
  • 理解 DRC 设计规则检查原理与 Gerber 制造文件输出的规范，能够将设计交付 PCB 工厂打样
  • 完成实战项目——STC89C52RC 最小系统板的原理图与 PCB 设计并输出可制造文件

Altium Designer（简称 AD）是澳大利亚 Altium 公司（前身 Protel International）推出的板级电子设计自动化（EDA）软件，是全球电子工程行业最主流的原理图与 PCB 设计工具之一。从 1985 年的 Protel for DOS 到今天的 Altium Designer 24，该软件经历了近 40 年的发展，凭借完整的"原理图—PCB—制造—仿真"一体化流程与友好的 Windows 原生界面，成为大量硬件工程师的首选工具。本章将系统介绍 Altium Designer 的安装配置、原理图设计、PCB 布局布线、DRC 检查、Gerber 输出，并通过 STC89C52RC 最小系统板实战项目串起完整工作流。

25.1 Altium Designer 简介与发展

25.1.1 软件定位与核心功能

Altium Designer 是一款板级电子设计一体化软件，将原理图捕获、PCB 布局布线、FPGA 设计、SPICE 仿真、信号完整性分析、库管理与制造文件输出集成于同一环境。其核心功能模块包括：

  • Schematic Editor（原理图编辑器）：用于绘制电路原理图，支持多页面、层次化设计、总线与网络标号。
  • PCB Editor（PCB 编辑器）：用于 PCB 布局、布线、铺铜、3D 视图，支持多层板设计（最多 32 层信号层）。
  • Library Editor（库编辑器）：包括原理图符号库（.SchLib）、PCB 封装库（.PcbLib）与集成库（.IntLib）。
  • SPICE Simulator（仿真器）：基于 XSPICE 引擎的混合信号电路仿真。
  • CAM Editor（CAM 编辑器）：用于 Gerber 文件检查、拼板与制造数据准备。

25.1.2 发展历程与版本演进

Altium Designer 的历史可追溯到 1985 年发布的 Protel for DOS。下表列出了其主要版本演进：

Altium Designer 在中端 EDA 市场占据主导地位，全球有超过 10 万家企业用户。其优势在于完整的设计链路、活跃的元件库生态（Altium Vault / Octopart）与对 Windows 平台的原生优化。下表给出与同类 EDA 工具的简要对比：

Altium Designer 对硬件有一定要求，尤其是 PCB 布线与大尺寸铺铜时对 CPU 与显卡的压力较大。下表给出官方推荐配置与最低配置：

显卡DirectX 11 兼容独立显卡 4 GB 显存
显示1920×10802560×1440 双显
本课程电脑配置参考：本课程实验环境为 Windows 11 专业版、CPU 至强 W7-2595X 24 核、内存 DDR5 48 GB、显卡 RTX pro 2000 16 GB 显存。该配置运行 Altium Designer 24 流畅无压力。学生个人电脑达到最低配置即可完成本章实验，复杂多层板设计建议升至 16 GB 内存。

25.2.2 下载与安装步骤

Altium Designer 提供 15 天免费试用，可在 Altium 官方网站（https://www.altium.com/）下载。完整安装步骤如下：

  1. 注册 Altium 账号：访问 Altium 官网，使用邮箱注册账号（用于试用授权与后续订阅）。
  2. 下载安装器：登录后进入 Downloads 页面，下载 AltiumDesignerSetup_xx_x_x.exe（约 2-3 GB）。
  3. 运行安装程序：双击安装器，选择安装目录（默认 C:\Program Files\Altium\AD22），勾选所需组件（核心 + Importers/Exporters + Examples）。
  4. 等待安装完成：安装过程约 15-30 分钟，取决于硬盘速度。
  5. 首次启动：运行 Altium Designer，在登录窗口输入 Altium 账号激活试用，或选择"Use trial version"。

25.2.3 授权方式说明

Altium Designer 的合法授权方式主要包括以下三类，本课程仅做客观陈述：

  • 商业订阅：按用户年度订阅，约 3000-10000 美元/年/用户，含官方技术支持与云端元件库访问。
  • 教育授权：高校可通过 Altium 大学计划申请免费或折扣教育授权，仅限教学与科研用途，不可商用。
  • 学生授权：在校大学生可申请免费 1 年学生版授权（功能完整，不可商用），到期可续。
学术诚信提示：本课程强烈建议通过教育授权或学生授权合法使用 Altium Designer。网络上流传的"破解版"不仅侵犯版权，还可能捆绑恶意软件导致电脑被控，且违反学术诚信原则，切勿使用。学校实验室通常已部署教育版，学生可直接使用。

25.2.4 首次运行与界面概览

首次启动 Altium Designer 后，主界面包括以下关键部分：

  • 顶部菜单栏：File / View / Project / Design / Tools / Reports / Window / Help。
  • 主工具栏：新建、打开、保存、打印、撤销/重做、缩放等快捷按钮。
  • 左侧面板区：Projects（工程树）、Navigator（导航）、Libraries（库）、Messages（消息）。
  • 中间工作区：原理图、PCB、库文件的编辑画布。
  • 右侧面板区：Properties（属性）、SCH Library、PCB Library。
  • 底部状态栏：当前坐标、栅格、单位、命令提示。

建议通过 View → Panels 菜单打开 Projects、Libraries、Properties、Messages 四个核心面板，并拖动到合适位置固定。完成首次配置后，建议执行 File → Save As Template 保存工作区布局，便于后续项目复用。

25.3 原理图设计基础

25.3.1 新建工程与原理图

Altium Designer 以工程（Project）为管理单元，一个工程包含原理图、PCB、库等关联文件。新建工程步骤：

  1. 执行 File → New → Project，弹出 New Project 对话框。
  2. 选择 PCB Project，命名（如 STC89_MinSys），选择保存路径。
  3. 工程文件扩展名为 .PrjPcb，出现在左侧 Projects 面板。
  4. 右键工程 → Add New to Project → Schematic，添加一张原理图。
  5. 原理图文件扩展名为 .SchDoc，自动打开为当前编辑画布。

25.3.2 文档选项设置

双击原理图空白处（或执行 Tools → Schematic Preferences）打开文档选项，常用配置：

  • Sheet Size：A4（默认）或 A3，复杂电路选 A3。
  • Orientation：Landscape（横向）。
  • Grids：Visible Grid = 10mil，Snap Grid = 10mil，确保元件对齐。
  • Standard Style：勾选 Show Border、Show Title Block。

25.3.3 放置元件与连线

原理图核心操作是放置元件（Place Part）与连线（Place Wire）。常用命令：

操作菜单命令快捷键说明
放置元件Place → PartP + P从库中选择并放置
放置导线Place → WireP + W连接元件引脚
放置网络标号Place → Net LabelP + N命名网络，同名即相连
放置电源端口Place → Power PortP + OVCC / GND 等电源符号
放置节点Place → Manual JunctionP + J交叉导线连接点
放置总线Place → BusP + B多条并行信号聚合
放置总线入口Place → Bus EntryP + E导线接入总线的斜线

放置元件时按 Tab 键可在放置前修改元件属性；放置过程中按 Space 旋转 90°、按 X 水平翻转、按 Y 垂直翻转。

25.3.4 电源端口与网络标号

电源端口（Power Port）是原理图中表示电源与地的特殊符号，常用类型包括 VCC、GND、+3.3V、+5V。放置电源端口后，所有同名电源端口自动连接，无需导线。建议为不同电压使用不同样式：VCC 用上箭头、GND 用三角地、+3.3V 用波形符号，提高可读性。

网络标号（Net Label）用于命名导线网络，相同名字的标号即视为电气连接。例如在单片机 P0 口的 8 条引脚分别添加 P00、P01...P07 标号，在排针处添加同样标号，即可建立电气连接，无需长导线穿越。

25.3.5 层次化原理图设计

对于复杂电路，AD 支持层次化设计：将系统拆分为多个子模块，每个子模块对应一张子原理图，通过 Sheet Symbol（图纸符号）与 Sheet Entry（图纸入口）连接。层次化设计有两种方向：

  • 自顶向下：先画顶层方块图，再为每个方块生成子图。
  • 自底向上：先画各子模块原理图，再生成顶层方块图。

对 STC89 最小系统板这种简单电路，单页原理图足够；对包含电源、主控、通信、显示多模块的项目，建议采用层次化设计以提高可维护性。

25.4 元件库管理

25.4.1 库文件类型

Altium Designer 的元件库分为三类：

  • 原理图符号库（.SchLib）：定义元件在原理图中的图形符号与引脚。
  • PCB 封装库（.PcbLib）：定义元件在 PCB 中的焊盘图形与外形。
  • 集成库（.IntLib）：将符号库、封装库、3D 模型、仿真模型打包成一个文件，是 AD 推荐的库形式。

AD 自带丰富的集成库，位于安装目录 \Library 下，常用的有：

  • Miscellaneous Devices.IntLib：电阻、电容、二极管、三极管、晶振等通用元件。
  • Miscellaneous Connectors.IntLib：排针、排母、DB9、USB 等连接器。
  • FPGA Generic.IntLib：FPGA 通用元件。
  • ST Microelectronics：意法半导体芯片（含 STM32 系列）。

25.4.2 安装与查找元件

安装库步骤：File → Open 选择 .IntLib 文件，弹出"是否编译为源码"对话框选 No，库即加入可用库列表。也可通过右侧 Libraries 面板的 File-based Libraries Preferences 按钮批量管理已安装库。

查找元件：Components 面板顶部搜索框输入元件名（如 STC89C52RC、0.1uF），如已安装库中无对应元件，可点击 Search 按钮启用全网搜索（含 Altium Vault 与 Octopart），在线下载集成库。

25.4.3 自定义元件创建

对于库中找不到的元件（如国产 STC89C52RC、CH340 等芯片），需自行创建。完整流程包括符号绘制 → 引脚定义 → 封装绘制 → 关联四步。以 STC89C52RC（PDIP-40 封装）为例：

1. 新建符号库

  1. File → New → Library → Schematic Library，生成 SchLib1.SchLib。
  2. 在 SCH Library 面板中重命名元件为 STC89C52RC。
  3. 使用 Place → Rectangle 绘制矩形框（约 800×1000 mil）。
  4. 使用 Place → Pin 放置 40 个引脚，按 STC89C52RC 引脚图设置 Designator（1-40）与 Display Name（P1.0~P1.7、P2.0~P2.7、P3.0~P3.7、P0.0~P0.7、VCC、GND、XTAL1、XTAL2、RST、EA、PSEN、ALE）。
  5. 注意引脚电气类型：电源为 Power、I/O 为 Passive/IO、复位为 Input。

2. 新建封装库

  1. File → New → Library → PCB Library，生成 PcbLib1.PcbLib。
  2. 在 PCB Library 面板中右键 → New Blank Component，命名为 DIP-40。
  3. 切换到 Top Overlay 层，绘制 40 脚 DIP 外框（约 1900×600 mil）。
  4. 切换到 Top Layer，放置 40 个焊盘（Pad），间距 100mil（同侧）、行距 600mil，焊盘外径 60mil、孔径 35mil。
  5. 1 号脚用方形焊盘标识，其余为圆形。

3. 关联符号与封装

在符号库中，打开 STC89C52RC 的属性 → Footprints → Add → Browse 选择 DIP-40，保存库文件。至此自定义元件完成，可在原理图中调用。

25.4.4 3D 模型与 STEP 文件

Altium Designer 支持为封装添加 3D 实体模型，使 PCB 可在 3D 视图中观察真实外观与机械干涉。添加 3D 模型步骤：

  1. 从芯片厂商官网下载 STEP（.step 或 .stp）3D 模型文件。
  2. 在 PCB Library 中切换到 Mechanical 1 层，执行 Place → 3D Body。
  3. 在弹出的对话框选择 STEP 文件导入，调整位置使其与焊盘对齐。
  4. 切换到 3D 视图（快捷键 3）验证外观。
3D 模型的作用：3D 模型不仅美观，更是机械干涉检查的关键。复杂 PCB 中接插件、电解电容、屏蔽罩等高度方向可能冲突，3D 视图可直观发现这些问题，避免打样后才发现装配失败。

25.5 PCB 设计基础

25.5.1 从原理图导入 PCB

原理图设计完成后，需将元件与网络信息同步到 PCB。步骤如下：

  1. 在工程中右键 → Add New to Project → PCB，生成 .PcbDoc 文件并保存。
  2. 打开原理图，执行 Design → Update PCB Document xxx.PcbDoc。
  3. 弹出 Engineering Change Order（ECO）对话框，列出所有要执行的变更（添加元件、网络、Room）。
  4. 点击 Validate Changes 验证，全部绿勾表示无错误；红叉需返回原理图检查。
  5. 点击 Execute Changes 执行，元件以 Room 形式出现在 PCB 画布右侧。

25.5.2 板框与叠层

导入元件后第一步是定义板框（Board Shape）：

  1. 切换到 Keep-Out Layer 或 Mechanical 1 层。
  2. 用 Place → Line 绘制闭合矩形（如 50mm×40mm）。
  3. 选中矩形，执行 Design → Board Shape → Define Board Shape from Selected Objects。
  4. 板框变为深色，完成定义。

叠层（Layer Stackup）通过 Design → Layer Stack Manager 配置。双层板默认有 Top Layer 与 Bottom Layer 两层信号层，中间为 FR-4 介质。可添加 Power Plane 与 GND Plane 形成四层板（适用于复杂高速电路）。本章实战项目使用双层板即可。

25.5.3 设计规则设置

PCB 布线前必须配置设计规则（Design Rules），通过 Design → Rules 打开规则管理器。常用规则：

规则类别规则名推荐值说明

25.5.4 元件布局原则

布局是 PCB 设计的关键步骤，布局好坏直接影响布线质量与电路性能。基本布局原则：

  • 先核心后外围：先放置主控芯片（如 STC89C52RC），再围绕其放置周边元件。
  • 去耦电容贴近 IC：每个 IC 的 VCC 与 GND 引脚附近放置 0.1µF 去耦电容，距离越近越好（< 5mm）。
  • 晶振紧邻 MCU：晶振与匹配电容紧靠 MCU 的 XTAL 引脚，走线尽量短而直，避免干扰。
  • 接插件靠边：电源接口、USB、排针等接插件放在板边缘，便于插拔与装配。
  • 信号流向清晰：按"输入→处理→输出"流向布局，避免信号交叉。
  • 方向一致：相同元件（如电阻、电容）尽量同方向排列，便于贴片加工。
  • 预留调试空间：关键测试点预留焊盘或测试环。

25.5.5 交互式布线

Altium Designer 提供强大的交互式布线引擎（Interactive Routing），支持推挤、绕障、自动避让。常用操作：

  1. 执行 Place → Interactive Routing（快捷键 P + T 或 Ctrl + W）。
  2. 从起始焊盘点击开始，移动光标拉出导线，按 Space 切换走线方向（水平/45°）。
  3. 遇到障碍时引擎自动绕开；按 Shift + R 切换避让模式（Ignore / Push / Stop）。
  4. 按 Shift + Space 切换转角风格（45° / 90° / 任意角度 / 圆弧）。
  5. 按 Tab 修改线宽与过孔尺寸。
  6. 到达终点焊盘点击完成，自动保持网络电气连接。

25.5.6 自动布线

对于复杂板卡，可使用 Situs 自动布线器辅助。执行 Auto Routing → All，弹出策略对话框选择 Default 2 Layer Board。但不建议完全依赖自动布线，实际项目中自动布线结果往往不满足电源/高速要求，应作为辅助手段，关键信号由人工布线。

25.6 DRC 设计规则检查

25.6.1 DRC 规则配置

DRC（Design Rule Check）是 PCB 投产前的最后一道质量关卡，确保设计满足工艺能力与电气规则。除 25.5.3 提到的常规规则外，还需检查：

  • Un-Routed Net：未布线网络，必须为 0。
  • Short-Circuit Constraint：不同网络短路，必须为 0。
  • Un-Connected Pin：未连接引脚，需逐一核对。
  • Silk to Solder Mask Shrinkage：丝印盖住焊盘。
  • Minimum Annular Ring：焊盘环形铜≥4mil。
  • Acute Angle：锐角走线，避免酸液陷阱。

25.6.2 运行 DRC

执行 Tools → Design Rule Check，在弹出的对话框中勾选要检查的规则类别，点击 Run Design Rule Check。AD 生成 .html 报告并自动打开，同时 Messages 面板列出所有违规项，每条违规在 PCB 中以红色高亮显示。

25.7.1 Gerber 文件规范

Gerber 是 PCB 行业的事实标准制造格式（RS-274X），由 Ucamco 公司维护。每个 Gerber 文件描述一个图层的光绘数据，包含线条、焊盘、文字等图形元素。一个双层板需要输出的 Gerber 文件包括：

25.7.2 钻孔与坐标文件

除 Gerber 外还需输出：

  • 钻孔文件（.TXT 或 .DRR）：描述所有过孔与通孔焊盘的位置、孔径。格式为 Excellon。
  • 贴片坐标文件（Pick & Place）：贴片机坐标，用于 SMT 加工。执行 File → Fabrication Outputs → Generates Pick and Place Files。
  • BOM 物料清单（.xls 或 .csv）：列出所有元件型号与数量，执行 Reports → Bill of Materials。

25.7.3 输出 Gerber 的步骤

  1. 打开 PCB 文件，执行 File → Fabrication Outputs → Gerber Files。
  2. 在 General 选项卡选择单位 Inches、精度 2:5（保留 5 位小数）。
  3. Layers 选项卡勾选所有需要的图层（按上表）。
  4. Drill Drawing 选项卡勾选生成钻孔图。
  5. Apertures 与 Advanced 选项卡保持默认。
  6. 点击 OK，生成 Project Outputs 文件夹，包含所有 .g* 文件。
  7. 执行 File → Fabrication Outputs → NC Drill Files 输出钻孔文件。
  8. 将所有文件打包为 ZIP，准备上传 PCB 工厂。

25.8 实战项目：STC89C52RC 最小系统板

本节通过一个完整项目串起前述所有知识点。我们将设计一款 STC89C52RC 最小系统板，板尺寸 50mm × 40mm，包含主控、晶振、复位、电源指示、ISP 接口与 GPIO 排针，可作为 STC89 学习与实验的基础平台。

25.8.1 设计目标与电路规划

STC89C52RC 最小系统板需要包含以下模块：

  • 主控芯片：STC89C52RC，PDIP-40 封装。
  • 晶振电路：12MHz 晶振 + 2 个 30pF 负载电容。
  • 复位电路：10µF 电解电容 + 10K 电阻，上电复位。
  • 电源指示：LED + 1K 限流电阻。
  • ISP 接口：4 脚排针（VCC / GND / TXD / RXD），连接 USB-TTL 模块下载程序。
  • GPIO 引出：P0、P1、P2、P3 各 8 脚通过排针引出。

25.8.2 原理图设计

新建工程 STC89_MinSys.PrjPcb 与原理图 STC89_MinSys.SchDoc。按以下顺序放置元件并连线：

  1. 放置 STC89C52RC（自定义符号库，见 25.4.3）于画布中央。
  2. 晶振 Y1（12MHz）+ 30pF 电容 C1、C2，连接到 MCU 的 XTAL1（引脚 19）与 XTAL2（引脚 18）。
  3. 复位电路：10µF 电容 C3 + 10K 电阻 R1，连接到 MCU 的 RST 引脚（引脚 9）。
  4. 电源指示 LED（D1）+ 1K 限流电阻 R2，连接到 VCC 与 GND。
  5. 放置 4 脚排针 P3，引脚定义 VCC / GND / TXD / RXD，连接 MCU 的 P3.0（RXD，引脚 10）与 P3.1（TXD，引脚 11）。
  6. 放置 2 个 8 脚排针 P1、P2，分别引出 P0（引脚 39-32）与 P1（引脚 1-8），P2、P3 类似（可用 4 个排针或 2 个 16 脚排针）。
  7. 添加 VCC 与 GND 电源端口，连接所有电源引脚。

原理图完成后，使用 Tools → Annotate Schematics Quietly 自动编号元件，便于 BOM 输出。导出的 BOM 简表如下：

位号型号封装数量

25.8.3 PCB 布局

执行 Design → Update PCB Document 将原理图同步到 PCB。在 50×40mm 板框内按以下原则布局：

  • STC89C52RC（U1）居中偏左，1 号脚朝左上，便于其余元件围绕排布。
  • 晶振 Y1 与 C1、C2 紧靠 U1 上方，连接 XTAL1/XTAL2。
  • 复位电路 C3、R1 位于 U1 右上方，靠近 RST 引脚。
  • 电源指示 LED 与 R2 放在板右上角，方便观察。
  • 排针 P1、P2 沿上下板边排列；ISP 接口 P3 放在左侧板边。
  • 电源去耦电容（每个 VCC 引脚 0.1µF，未列入主 BOM）紧贴 U1 第 40 脚与第 20 脚。

25.8.4 PCB 布线

设置设计规则：Clearance = 10mil、Width Signal = 10mil、Width Power = 20mil、Via 24/12mil。布线顺序：

  1. 电源线优先：VCC 与 GND 用 20mil 宽线，从 P3 电源引脚出发，连接 U1 的 40 脚（VCC）与 20 脚（GND），再分支到其他元件。
  2. 晶振电路：XTAL1/XTAL2 走线短直，不绕过其他信号。
  3. 复位电路：RST 引脚到 C3/R1 节点走线尽量短。
  4. GPIO 引出：P0/P1/P2/P3 引脚到排针走线尽量不交叉，必要时使用过孔换层。
  5. 顶层铺铜：顶层 GND 铺铜，底层 GND 铺铜，形成完整地平面。

布线完成后执行 Tools → Teardrops 添加泪滴焊盘，提升焊接可靠性。最终 PCB 顶层效果：主控居中，晶振、复位、LED 分布四周，铺铜覆盖空白区域。

25.8.5 DRC 检查与修复

执行 Tools → Design Rule Check，常见需修复项：

  • 排针焊盘与铺铜间距不足 → 调整 Polygon Connect Style 或铺铜间距。
  • 晶振走线未连通 → 检查原理图 XTAL 网络是否正确。
  • 丝印重叠焊盘 → 移动丝印位置。

清零 DRC 错误后，PCB 设计完成。

25.8.6 Gerber 输出与打样

按 25.7.3 步骤输出 Gerber 与钻孔文件，打包为 STC89_MinSys_Gerber.zip。访问嘉立创下单页（jlcpcb.com），上传 ZIP，参数选择：

下单后通常 24-48 小时内发货，3-5 天到货。收到 PCB 后焊接元件，连接 USB-TTL 模块，使用 STC-ISP 烧录第 5 章的 LED 闪烁程序，验证最小系统板工作正常。

25.9.3 高级技巧

  • 铺铜（Polygon Pour）：在大面积空白区域铺铜并连接到 GND，可降低地阻抗、提高 EMI 性能。执行 Place → Polygon Pour，选择 GND 网络，勾选 Pour Over All Same Net Objects。
  • 泪滴焊盘（Teardrops）：在焊盘与导线连接处添加泪滴形过渡，减少焊接应力。执行 Tools → Teardrops → Add。
  • 设计复用：将常用电路（如 USB-TTL、电源模块）保存为 Device Sheet 或Snippet，下次项目直接调用。
  • 3D 干涉检查：在 3D 视图下与机械结构 STEP 文件对比，提前发现装配冲突。
  • 批量修改属性：使用 SCHLIB List 或 PCB List 面板，类似 Excel 批量编辑元件属性。
  • 差分对走线：USB、CAN、RS-485 等差分信号使用 Design → Differential Pairs Routing 自动等长等距走线。

25.10.2 学习建议

  1. 以 Altium Designer 为主：AD 在国内就业市场认可度最高，本科阶段掌握 AD 即可满足绝大多数岗位需求。

本章小结

  • Altium Designer 是行业主流的板级 EDA 软件，覆盖原理图、PCB、库管理、仿真、制造一体化流程，国内就业市场认可度高。
  • 软件安装需通过 Altium 官网下载，授权推荐使用教育授权或学生授权合法获取，切勿使用破解版。
  • 原理图设计核心是放置元件、连线、网络标号、电源端口；PCB 设计核心是导入网络表、布局、布线、铺铜，去耦电容贴近 IC、晶振紧邻 MCU、接插件靠边是布局三大原则。
  • DRC 是投产前最后质量关卡，必须 0 错误；Gerber 文件是 PCB 行业事实标准制造格式，需配合钻孔文件、BOM 一并交付工厂。
  • 实战项目 STC89C52RC 最小系统板完整串起原理图设计、PCB 布局布线、DRC、Gerber 输出全流程，可作为后续实验与毕业设计的硬件平台。
  • Altium Designer 与嘉立创 EDA、KiCad、Cadence、PADS 各有定位，建议以 AD 为主、嘉立创 EDA 为辅，理解原理比工具本身更重要。
