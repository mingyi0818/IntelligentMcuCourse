第 32 章 智能温控风扇（STM32F407）

学习目标

  • 掌握 STM32F407 + DS18B20 + OLED + PWM 风扇的硬件系统集成方法
  • 学会使用定时器 PWM 输出实现直流风扇的无级调速
  • 掌握 DS18B20 单总线温度传感器的协议驱动与数据滤波算法
  • 理解 PID 控制算法在温度闭环控制中的应用与参数整定
  • 能独立完成智能温控风扇项目的调试，并能扩展为物联网上报节点

32.1 项目需求

本项目设计一款基于 STM32F407VET6 的智能温控风扇，根据环境温度自动调节风扇转速，并通过 OLED 显示当前状态。具体需求：

  • 温度采集：DS18B20 周期采样（500 ms），精度 ±0.5°C，量程 -10°C~85°C。
  • PWM 调速：12 V 直流风扇由 MOS 管驱动，PWM 频率 25 kHz，占空比 0~100%。
  • OLED 显示：0.96" OLED（SSD1306，I2C）显示当前温度、目标温度、PWM 占空比、风速档位。
  • 按键调阈值：3 个按键（设置 / + / -），可调整目标温度 20°C~35°C，步进 1°C。
  • 多模式：自动 PID 模式 + 手动 3 档模式，长按"设置"键 3 秒切换。

32.2 硬件设计

系统硬件以 STM32F407VET6 为核心，外围模块包括 DS18B20 温度传感器、SSD1306 OLED 显示、按键、12V PWM 风扇（经 AO3400 N-MOS 驱动）。详细接线如下表：

模块引脚STM32 端口说明

关键设计：12V 风扇电源与 3.3V 单片机电源必须共地，否则 PWM 信号无法驱动 MOS 栅极；栅极串 100Ω 电阻可抑制尖峰，并联 10kΩ 下拉电阻可防止上电瞬间 MOS 误导通。

32.4 关键算法

32.4.1 PID 调速算法

32.4.1.1 位置式 PID 公式与抗饱和策略

采用位置式 PID算法，根据温度偏差计算 PWM 占空比。设目标温度 $T_{sp}$（Setpoint），实测温度 $T_{pv}$（Process Variable），偏差 $e(k) = T_{sp} - T_{pv}$。离散 PID 公式为：

$$u(k) = K_p\,e(k) + K_i\sum_{j=0}^{k} e(j) + K_d\,[e(k) - e(k-1)]$$

其中 $u(k)$ 为输出占空比（0~100）。为避免积分饱和，加入积分分离与输出限幅：当 $|e(k)| > 5°C$ 时关闭积分项；当 $u(k) > 100$ 时取 100，$u(k) < 0$ 时取 0。C 语言实现：

32.4.1.2 PID 控制器代码实现

/* pid.c - 位置式 PID 控制器 */
#include "pid.h"

typedef struct {
    float Kp, Ki, Kd;
    float integral;
    float prev_err;
    float out_max, out_min;
} PID_t;

float PID_Compute(PID_t *pid, float setpoint, float pv) {
    float err = setpoint - pv;
    float delta = err - pid->prev_err;

    /* 积分分离：偏差过大时关闭积分项 */
    if (fabsf(err) <= 5.0f) {
        pid->integral += err;
    }
    /* 抗饱和：积分项限幅 */
    if (pid->integral > 50.0f) pid->integral = 50.0f;
    if (pid->integral < -50.0f) pid->integral = -50.0f;

    float u = pid->Kp * err + pid->Ki * pid->integral + pid->Kd * delta;

    /* 输出限幅 */
    if (u > pid->out_max) u = pid->out_max;
    if (u < pid->out_min) u = pid->out_min;

    pid->prev_err = err;
    return u;
}

/* 在 Task_PID 中调用，温度反向控制：温度↑→转速↑ */
void Task_PID(void *arg) {
    PID_t pid = { .Kp = 8.0f, .Ki = 0.5f, .Kd = 2.0f,
                  .integral = 0, .prev_err = 0,
                  .out_max = 100.0f, .out_min = 0.0f };
    float temp, sp = 28.0f;
    while (1) {
        xQueuePeek(xQueue_Temp, &temp, 0);
        xQueuePeek(xQueue_Setpoint, &sp, 0);
        float u = PID_Compute(&pid, sp, temp);   /* u 单位 % */
        uint32_t ccr = (uint32_t)(u * 10.0f);       /* ARR=1000，1% = 10 */
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, ccr);
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}

32.4.2 温度滑动平均滤波

32.4.2.1 滑动平均滤波原理

DS18B20 单次读数可能受干扰抖动，采用 5 点滑动平均提升稳定性。设原始采样序列 $x_n$，滤波后输出 $y_n$：

$$y_n = \frac{1}{5}\sum_{i=0}^{4} x_{n-i}$$

32.4.2.2 滤波算法实现

/* filter.c - 5 点滑动平均滤波 */
#define WIN 5
static float buf[WIN];
static uint8_t idx = 0;

float Filter_MovingAvg(float x) {
    buf[idx] = x;
    idx = (idx + 1) % WIN;
    float sum = 0;
    for (uint8_t i = 0; i < WIN; i++) sum += buf[i];
    return sum / WIN;
}

32.4.3 DS18B20 驱动核心

32.4.3.1 单总线时序与读写函数

DS18B20 是 Maxim 单总线数字温度传感器，分辨率 9~12 位可调。STM32 用 GPIO 模拟单总线时序：

/* ds18b20.c - 关键函数 */
#include "ds18b20.h"

extern TIM_HandleTypeDef htim1;   /* us 级延时 */
static void Delay_us(uint16_t us) {
    __HAL_TIM_SET_COUNTER(&htim1, 0);
    while (__HAL_TIM_GET_COUNTER(&htim1) < us);
}

/* 单总线复位：拉低 480us，等待 60us 后读取存在脉冲 */
uint8_t DS18B20_Reset(void) {
    uint8_t presence;
    DS18B20_SetOutput();
    DS18B20_PinLow();
    Delay_us(480);
    DS18B20_SetInput();
    Delay_us(60);
    presence = (DS18B20_ReadPin() == 0) ? 1 : 0;
    Delay_us(420);
    return presence;
}

void DS18B20_WriteByte(uint8_t dat) {
    DS18B20_SetOutput();
    for (uint8_t i = 0; i < 8; i++) {
        DS18B20_PinLow();
        Delay_us(2);
        if (dat & 0x01) DS18B20_PinHigh(); else DS18B20_PinLow();
        Delay_us(60);
        DS18B20_PinHigh();
        dat >>= 1;
    }
}

uint8_t DS18B20_ReadByte(void) {
    uint8_t dat = 0;
    for (uint8_t i = 0; i < 8; i++) {
        DS18B20_SetOutput();
        DS18B20_PinLow();
        Delay_us(2);
        DS18B20_SetInput();
        Delay_us(10);
        dat >>= 1;
        if (DS18B20_ReadPin()) dat |= 0x80;
        Delay_us(50);
    }
    return dat;
}

float DS18B20_ReadTemp(void) {
    uint8_t l, h;
    int16_t raw;
    if (!DS18B20_Reset()) return -999.0f;
    DS18B20_WriteByte(0xCC);   /* Skip ROM */
    DS18B20_WriteByte(0x44);   /* Convert T */
    HAL_Delay(750);            /* 12-bit 转换时间 */
    DS18B20_Reset();
    DS18B20_WriteByte(0xCC);
    DS18B20_WriteByte(0xBE);   /* Read Scratchpad */
    l = DS18B20_ReadByte();
    h = DS18B20_ReadByte();
    raw = (h << 8) | l;
    return raw * 0.0625f;       /* 12-bit: 0.0625°C/LSB */
}

32.4.3.2 转换时间与工程注意事项

注意 DS18B20 转换时间随分辨率变化：9 位 93.75 ms，12 位 750 ms。在 FreeRTOS 任务中用 `HAL_Delay()` 会阻塞任务，工程上应改为软件定时器或将任务拆分。

32.6 调试与扩展方向

常见调试问题：

  • DS18B20 读温度为 -999：检查 4.7kΩ 上拉电阻；us 级延时必须用 TIM 实现，不能用 HAL_Delay。
  • PWM 不输出：确认 TIM3_CH1 引脚为 PC6，CubeMX 中将通道配置为 PWM Generation；ARR=1000、PSC=0 时 84 MHz 主频下 PWM 频率为 84 kHz，按 25 kHz 设定则 PSC = 3。
  • 系统震荡：PID 参数过大，先全置 0 仅保留 Kp 调试，再加入 Kd，最后加 Ki。
  • 风扇启动时 STM32 复位：风扇电源与单片机电源未共地或未加去耦电容；建议风扇 12V 独立电源，与单片机共地点单点连接。

扩展方向：

  • IoT 上报：增加 ESP8266 通过 MQTT 协议上报温度与 PWM 数据到云端（如 OneNET、阿里云），实现远程监控。
  • 多传感器融合：加入 DHT11 湿度传感器，根据"体感温度"调整风扇转速，提升用户体验。
  • 自适应 PID：根据温度偏差大小动态切换 PID 参数组（Bang-Bang + PID 双模）。
  • 低功耗模式：温度低于阈值时关闭 PWM 输出并让 MCU 进入 Stop 模式，由 DS18B20 报警唤醒。

本章小结

  • 智能温控风扇综合运用了 STM32 定时器 PWM、单总线、I2C、FreeRTOS、PID 算法等知识。
  • 硬件设计需特别注意电源隔离、共地与去耦，避免风扇开关噪声干扰单片机。
  • 位置式 PID 配合积分分离与输出限幅是嵌入式控制的标准做法。
  • DS18B20 单总线协议的 us 级时序是调试难点，必须借助 TIM 实现精确延时。
  • 工程扩展可向 IoT 上报、多传感器融合、自适应控制等方向发展。
