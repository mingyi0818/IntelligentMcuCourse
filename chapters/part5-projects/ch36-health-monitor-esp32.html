第 36 章 智能健康监测（ESP32+MAX30102）

学习目标

  • 掌握基于 ESP32 + MAX30102 的可穿戴健康监测系统需求分析与架构设计
  • 理解光体积描记法（PPG）测量心率（HR）与血氧饱和度（SpO2）的物理原理
  • 学会使用 I2C 协议配置 MAX30102 寄存器，正确读取 FIFO 数据
  • 掌握直流/交流分离、自相关法心率计算、R 比值法 SpO2 计算等关键算法
  • 能独立完成 OLED 波形显示、BLE 蓝牙数据上传与运动伪影抑制
  • 了解医疗器械电气安全、数据隐私与伦理合规的基本要求

§36.1 项目需求分析

§36.1.1 项目背景

智慧医疗是物联网技术最重要的应用领域之一。随着人口老龄化加剧和慢病管理需求上升，可穿戴式生理参数监测设备成为家庭健康管理的核心终端。其中，心率（Heart Rate, HR）和血氧饱和度（Peripheral Capillary Oxygen Saturation, SpO2）是反映心血管与呼吸系统状态的两项关键指标。

本项目基于乐鑫 ESP32 双核 MCU 与美信（Maxim Integrated，现属 ADI）MAX30102 集成光学传感器，构建一个完整的腕式/指夹式健康监测终端，可实时显示 PPG 波形并计算 HR、SpO2，同时通过低功耗蓝牙（BLE）将数据上传到手机 APP，实现家庭场景下的连续健康监测。

§36.1.2 功能需求

  • 生理参数采集：通过 MAX30102 红光（RED, 660 nm）+ 红外光（IR, 880 nm）双 LED 采集 PPG 信号，采样率 100 Hz，ADC 18 位。
  • 心率计算：使用自相关法从 IR 信号的交流分量中提取基频，计算心率，量程 30~250 BPM，分辨率 1 BPM。
  • 血氧饱和度计算：基于红光/红外光交流-直流比 R 值，按经验公式计算 SpO2，量程 70%~100%，分辨率 1%。
  • OLED 实时显示：0.96 英寸 SSD1306 OLED 同屏显示心率数值、SpO2 数值与 IR 通道 PPG 波形（滚动刷新）。
  • BLE 数据上传：作为 BLE 外设，每秒通过自定义 GATT 服务向手机推送 HR、SpO2、波形峰值，APP 端可绘制趋势曲线。
  • 低功耗运行：3.7 V 锂电池 + TP4056 充电管理，连续工作时长 ≥ 8 小时；待机电流 ≤ 1 mA。
  • 异常报警：HR < 50 或 > 120、SpO2 < 90% 时 OLED 反色闪烁并在 BLE 通道推送告警标志位。

§36.1.4 医疗应用场景与伦理

§36.1.4.1 合规注意事项

本项目属于"消费级健康监测设备"，与"医疗器械"之间存在明确界限。实际开发中需注意以下几点：

  • 设备定位：消费级设备用于日常健康参考，不可用于临床诊断。若需进入医疗器械注册流程，须满足 IEC 60601-1 电气安全、ISO 80601-2-61 脉搏血氧设备专用要求等标准。
  • 数据真实性：算法输出必须如实反映传感器数据，不得在硬件未测量时编造数值，亦不得通过软件"美化"无效测量。
  • 用户隐私：生理数据属于个人敏感信息。BLE 通信须使用配对加密（LE Secure Connections）；手机端 APP 上传云端须明示告知用户并获得授权。
  • 知情同意：测试受试者需知晓数据用途、存储位置与删除方式；未成年人数据应由监护人授权。
  • 误用风险：在低灌注、深色皮肤、运动伪影场景下 SpO2 误差增大，设备须明确提示"测量可能不准确"，避免延误就医。

§36.1.4.2 教学使用提示

提示：MAX30102 是消费级传感器，并非医用级（如 Nonin、Masimo）。教学项目不可作为医疗诊断依据，但可用于学习 PPG 信号处理与可穿戴系统设计方法。

§36.2 系统架构设计

系统采用 ESP32 作为主控，通过 I2C 总线同时挂载 MAX30102 与 SSD1306 OLED（共享同一总线，地址不同：MAX30102 = 0x57，OLED = 0x3C）。MAX30102 的中断引脚 INT 连接到 ESP32 GPIO19，FIFO 满或转换完成后触发中断，避免轮询开销。BLE 协议栈由 ESP-IDF 内置的 Bluedroid 提供，Arduino 框架封装为 BLEDevice API。

§36.4 MAX30102 工作原理与 I2C 协议

§36.4.1 PPG 光体积描记法原理

§36.4.1.1 PPG 信号生成机制

PPG（Photoplethysmography）是一种基于光电技术的容积描记方法。其物理本质是：心脏每次收缩时动脉血液灌注量瞬时增大，血液对光的吸收也瞬时增强，因此光电探测器接收到的反射（或透射）光强度呈现周期性波动。

§36.4.1.2 信号分量与血氧原理

PPG 信号可分解为两个分量：

  • 直流分量 DC：由骨骼、肌肉、静脉血、皮下组织等"非搏动性"吸收决定，幅度大、变化缓慢。
  • 交流分量 AC：由动脉搏动产生，频率即为心率，幅度约为 DC 的 1%~5%。

红光（660 nm）与红外光（880 nm）的吸光特性对氧合血红蛋白（HbO2）和脱氧血红蛋白（Hb）的吸收差异不同：HbO2 对红外光吸收更多，Hb 对红光吸收更多。两路 AC/DC 比值的比值 R 即可反映血氧饱和度。

§36.4.3.2 寄存器位域配置

SPO2_CONFIG 寄存器位域结构为：[6:5] ADC_range | [4:2] SR | [1:0] LED_PW。本项目取 ADC_range=01（4096 nA）、SR=011（100 Hz）、PW=11（215 µs, 17 bit），即 0x27。FIFO_CONFIG（0x08）取 SMP_AVE=010（4 平均）、FIFO_ROLLOVER_ON=1、FIFO_A_FULL=10001（17），即 0x5F。

§36.4.4 FIFO 读取协议

MAX30102 的 FIFO 深度为 32，每个样本占 6 字节（SpO2 模式下：红光 3 字节 + 红外 3 字节，MSB 优先）。读取流程为：

  1. 读取 INTR_STATUS_1（0x00）清除中断标志。
  2. 读取 FIFO_WR_PTR（0x04）与 FIFO_RD_PTR（0x06），计算样本数 num = (WR - RD + 32) % 32。
  3. 从 FIFO_DATA（0x07）连续读取 num * 6 字节。
  4. 每 3 字节拼成 18 位（高 2 位补 0，左移后取低 18 位）。

§36.5.2 关键算法原理

直流/交流分离

使用滑动平均滤波提取直流分量：

DC[i] = (1/N) Σ x[i-k], k = 0..N-1，N = 100（即 1 秒）。

交流分量为 AC[i] = x[i] - DC[i]。再通过 0.5~5 Hz 带通滤波抑制呼吸基线漂移与高频噪声。

自相关法心率计算

对 4 秒 AC 信号 x[n] 计算自相关函数：

R(τ) = Σ x[n] · x[n+τ]

在 τ ∈ [0.24 s, 2 s]（对应 30~250 BPM）范围内寻找 R(τ) 的极大值点 τpeak，则心率：

HR = 60 × fs / τpeak [BPM]

自相关法相比简单峰值检测具有更强抗噪性，但计算量为 O(N²)，需在 ESP32 上用 4 秒 × 100 Hz = 400 样本实现，约 16 万次乘加，耗时 < 10 ms。

R 比值法 SpO2 计算

计算红光与红外光的 RMS 交流值与直流值：

R = (AC_red / DC_red) / (AC_ir / DC_ir)

经验公式：

SpO2 = 104 - 17 × R (%)

R 值通常在 0.4~1.0 之间，对应 SpO2 在 87%~97%。该公式因传感器批次、贴片方式不同需要标定，工程上常以指夹式医用血氧仪为参考做线性回归修正。

/* ============ 引脚与常量 ============ */
#define SDA_PIN        21
#define SCL_PIN        22
#define INT_PIN        19
#define SCREEN_W       128
#define SCREEN_H       64
#define OLED_ADDR      0x3C
#define SAMPLE_RATE_HZ 100
#define BUF_SECONDS    4
#define BUF_LEN        (SAMPLE_RATE_HZ * BUF_SECONDS)   /* 400 */

/* ============ 全局对象 ============ */
Adafruit_SSD1306 display(SCREEN_W, SCREEN_H, &Wire, -1);
MAX30105 particleSensor;

/* BLE 服务与特征 UUID（自定义） */
#define SERVICE_UUID        "6E400001-B5A3-F393-E0A9-E50E24DCCA9E"
#define CHAR_HR_UUID        "6E400002-B5A3-F393-E0A9-E50E24DCCA9E"
#define CHAR_SPO2_UUID      "6E400003-B5A3-F393-E0A9-E50E24DCCA9E"
#define CHAR_WAVE_UUID      "6E400004-B5A3-F393-E0A9-E50E24DCCA9E"
BLEServer*         pServer = nullptr;
BLECharacteristic* pCharHR = nullptr;
BLECharacteristic* pCharSpO2 = nullptr;
BLECharacteristic* pCharWave = nullptr;
bool deviceConnected = false;

/* ============ PPG 数据缓冲 ============ */
uint32_t irBuf[BUF_LEN];       /* 红外光原始样本 */
uint32_t redBuf[BUF_LEN];      /* 红光原始样本   */
float    irAC[BUF_LEN];        /* 红外交流分量   */
float    redAC[BUF_LEN];       /* 红光交流分量   */
int      bufIdx = 0;
bool     bufFull = false;

/* 当前测量结果 */
volatile uint8_t  g_hr = 0;        /* BPM */
volatile uint8_t  g_spo2 = 0;      /* % */
volatile bool     g_hrValid = false;
volatile bool     g_spo2Valid = false;

/* OLED 波形显示游标 */
int waveX = 0;

/* ============ BLE 连接回调 ============ */
class ServerCallbacks: public BLEServerCallbacks {
  void onConnect(BLEServer* s) {
    deviceConnected = true;
  }
  void onDisconnect(BLEServer* s) {
    deviceConnected = false;
    BLEDevice::startAdvertising();
  }
};

/* ============ 传感器初始化 ============ */
bool initSensor() {
  if (!particleSensor.begin(Wire, I2C_SPEED_FAST)) return false;
  particleSensor.setup(
      60,                       /* LED 亮度 0~255，约 11.4 mA */
      4,                        /* 样本平均 4 */
      2,                        /* LED 脉宽 215µs, 17 bit */
      100,                      /* 采样率 100 Hz */
      4096,                     /* ADC 范围 4096 nA */
      0x1F);                    /* SpO2 模式，红光+红外 */
  particleSensor.enableAFULL(); /* FIFO 满中断 */
  particleSensor.setPulseAmplitudeRed(0x0A);
  particleSensor.setPulseAmplitudeIR(0x0A);
  return true;
}

/* ============ OLED 初始化 ============ */
void initOLED() {
  display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDR);
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(WHITE);
  display.setCursor(0, 0);
  display.println(F("ESP32 Health Monitor"));
  display.println(F("Booting..."));
  display.display();
}

/* ============ BLE 初始化 ============ */
void initBLE() {
  BLEDevice::init("ESP32_HealthMonitor");
  BLEDevice::setMTU(185);
  pServer = BLEDevice::createServer();
  pServer->setCallbacks(new ServerCallbacks());
  BLEService* pService = pServer->createService(SERVICE_UUID);

  pCharHR   = pService->createCharacteristic(
      CHAR_HR_UUID, BLECharacteristic::PROPERTY_NOTIFY);
  pCharSpO2 = pService->createCharacteristic(
      CHAR_SPO2_UUID, BLECharacteristic::PROPERTY_NOTIFY);
  pCharWave = pService->createCharacteristic(
      CHAR_WAVE_UUID, BLECharacteristic::PROPERTY_NOTIFY);

  pCharHR->addDescriptor(new BLE2902());
  pCharSpO2->addDescriptor(new BLE2902());
  pCharWave->addDescriptor(new BLE2902());

  pService->start();
  BLEAdvertising* pAdv = BLEDevice::getAdvertising();
  pAdv->addServiceUUID(SERVICE_UUID);
  pAdv->setScanResponse(true);
  BLEDevice::startAdvertising();
}

/* ============ 读取 PPG 样本 ============ */
/* 每次最多读 32 个样本入缓冲，缓冲满后置 bufFull=true */
void readPPG() {
  uint8_t numSamples = particleSensor.available();
  if (numSamples == 0) return;
  for (uint8_t i = 0; i < numSamples; i++) {
    redBuf[bufIdx] = particleSensor.getRed();
    irBuf[bufIdx]  = particleSensor.getIR();
    particleSensor.nextSample();
    bufIdx++;
    if (bufIdx >= BUF_LEN) {
      bufIdx = 0;
      bufFull = true;
    }
  }
}

/* ============ 直流/交流分离 ============ */
/* 滑动平均 1 秒（100 样本）求 DC，AC = x - DC */
void separateDC_AC() {
  const int win = 100;
  uint32_t sumRed = 0, sumIr = 0;
  /* 初始窗口 */
  for (int k = 0; k < win; k++) {
    sumRed += redBuf[k];
    sumIr  += irBuf[k];
  }
  for (int i = 0; i < BUF_LEN; i++) {
    float dcRed = (float)sumRed / win;
    float dcIr  = (float)sumIr  / win;
    redAC[i] = (float)redBuf[i] - dcRed;
    irAC[i]  = (float)irBuf[i]  - dcIr;
    /* 滑动窗口 */
    sumRed += redBuf[(i + win) % BUF_LEN] - redBuf[i];
    sumIr  += irBuf[(i + win) % BUF_LEN]  - irBuf[i];
  }
}

/* ============ 自相关法计算心率 ============ */
uint8_t calcHeartRate() {
  /* 仅用 IR 通道 AC 分量，搜索 τ ∈ [24, 200]（30~250 BPM） */
  const int tauMin = 24;
  const int tauMax = 200;
  float bestR = 0;
  int   bestTau = 0;
  for (int tau = tauMin; tau <= tauMax; tau++) {
    float r = 0;
    for (int n = 0; n < BUF_LEN - tau; n++) {
      r += irAC[n] * irAC[n + tau];
    }
    if (r > bestR) { bestR = r; bestTau = tau; }
  }
  if (bestTau == 0) return 0;
  /* 排除与零延迟的相关性（恒为最大） */
  float r0 = 0;
  for (int n = 0; n < BUF_LEN; n++) r0 += irAC[n] * irAC[n];
  if (bestR < 0.5 * r0) return 0;     /* 信噪比不足 */
  return (uint8_t)(60.0f * SAMPLE_RATE_HZ / bestTau + 0.5f);
}

/* ============ R 比值法计算 SpO2 ============ */
uint8_t calcSpO2() {
  /* 计算 IR 与 RED 的 RMS 交流与平均直流 */
  float sumIr = 0, sumRed = 0;
  float sqIr = 0, sqRed = 0;
  for (int i = 0; i < BUF_LEN; i++) {
    sumIr  += irBuf[i];
    sumRed += redBuf[i];
    sqIr   += irAC[i]  * irAC[i];
    sqRed  += redAC[i] * redAC[i];
  }
  float dcIr  = sumIr  / BUF_LEN;
  float dcRed = sumRed / BUF_LEN;
  float acIr  = sqrtf(sqIr  / BUF_LEN);
  float acRed = sqrtf(sqRed / BUF_LEN);
  if (dcIr < 1 || dcRed < 1) return 0;
  float R = (acRed / dcRed) / (acIr / dcIr);
  float spo2 = 104.0f - 17.0f * R;
  if (spo2 < 70) spo2 = 70;
  if (spo2 > 100) spo2 = 100;
  return (uint8_t)(spo2 + 0.5f);
}

/* ============ OLED 波形绘制 ============ */
void drawWave() {
  static int lastY = SCREEN_H / 2;
  /* 取最新 AC 样本归一化到 0~40 像素 */
  int idx = (bufIdx - 1 + BUF_LEN) % BUF_LEN;
  float v = irAC[idx];
  /* 自适应增益：以 1 秒内最大值为满刻度 */
  int y = SCREEN_H / 2 - (int)(v / 200.0f);
  if (y < 16) y = 16;
  if (y > 60) y = 60;
  /* 画线 */
  display.drawLine(waveX, lastY, waveX + 1, y, WHITE);
  display.drawLine(waveX, 16, waveX, 60, BLACK); /* 清旧点 */
  display.drawLine(waveX, 16, waveX, 60, WHITE);
  /* 实际项目用局部刷新 + 双缓冲消除闪烁 */
  lastY = y;
  waveX++;
  if (waveX >= SCREEN_W) waveX = 0;

  /* 顶部数值条 */
  display.fillRect(0, 0, SCREEN_W, 14, BLACK);
  display.setCursor(0, 0);
  display.setTextColor(WHITE);
  if (g_hrValid)
    display.printf("HR:%3d", g_hr);
  else
    display.print("HR:---");
  display.setCursor(64, 0);
  if (g_spo2Valid)
    display.printf("SpO2:%3d%%", g_spo2);
  else
    display.print("SpO2:--%");
  display.display();
}

/* ============ BLE 数据推送 ============ */
void bleNotify() {
  if (!deviceConnected) return;
  uint8_t hr[2]  = { g_hr, (uint8_t)(g_hrValid ? 1 : 0) };
  uint8_t sp[2]  = { g_spo2, (uint8_t)(g_spo2Valid ? 1 : 0) };
  /* 异常告警标志位 */
  uint8_t alert = 0;
  if (g_hrValid && (g_hr < 50 || g_hr > 120)) alert |= 0x01;
  if (g_spo2Valid && g_spo2 < 90) alert |= 0x02;
  sp[1] |= alert << 4;
  /* 推送最新 4 个波形点 */
  uint8_t wave[5] = {0};
  wave[0] = 4;
  for (int i = 0; i < 4; i++) {
    int idx = (bufIdx - 4 + i + BUF_LEN) % BUF_LEN;
    wave[i + 1] = (uint8_t)((irAC[idx] / 1000.0f) + 128);
  }
  pCharHR->setValue(hr, 2);
  pCharHR->notify();
  pCharSpO2->setValue(sp, 2);
  pCharSpO2->notify();
  pCharWave->setValue(wave, 5);
  pCharWave->notify();
}

/* ============ setup / loop ============ */
void setup() {
  Serial.begin(115200);
  Wire.begin(SDA_PIN, SCL_PIN, 400000);
  pinMode(INT_PIN, INPUT_PULLUP);

  initOLED();
  initBLE();
  if (!initSensor()) {
    display.clearDisplay();
    display.setCursor(0, 0);
    display.println("MAX30102 NOT FOUND");
    display.display();
    while (1) delay(1000);
  }
  Serial.println("Health Monitor Ready");
}

void loop() {
  readPPG();
  /* 缓冲满后做一次完整计算 */
  if (bufFull) {
    bufFull = false;
    separateDC_AC();
    uint8_t hr = calcHeartRate();
    if (hr > 0) { g_hr = hr; g_hrValid = true; }
    uint8_t sp = calcSpO2();
    if (sp > 0) { g_spo2 = sp; g_spo2Valid = true; }
    bleNotify();
    Serial.printf("HR=%d BPM, SpO2=%d%%\n", g_hr, g_spo2);
  }
  drawWave();
  delay(10);     /* ~100Hz 主循环 */
}

§36.5.3.2 代码设计要点

上述代码体现了几个工程化要点：

  • 缓冲满才计算：每凑满 4 秒数据做一次完整 HR/SpO2 计算，避免单点噪声影响。
  • 滑动平均分离 DC：避免了 FFT 的运算量，1 秒窗口平滑跟踪呼吸基线漂移。
  • 自相关法抗噪：相比峰值检测对幅值波动不敏感，且 bestR < 0.5 * r0 的判据可以剔除无效数据。
  • BLE 推送独立特征：HR、SpO2、波形分别使用不同 UUID，便于 APP 端订阅分离处理；告警标志位编码进 SpO2 特征的高 4 位。
  • 异常告警：HR < 50 / > 120、SpO2 < 90% 时通过 alert 位告知 APP，APP 可触发震动或语音提示。

§36.6.3 运动伪影处理

§36.6.3.1 处理方法

运动伪影（Motion Artifact）是 PPG 信号的最大干扰源，主要由手腕或手指运动引起皮肤与传感器相对位移。常用处理方法：

  • 硬件层面：增加传感器与皮肤的接触压力（腕带紧固），使用柔性 FPC 减小机械共振。
  • 滤波层面：3 阶 Butterworth 带通 0.5~4 Hz，比简单滑动平均更陡峭；自适应陷波滤除 50 Hz 工频。
  • 自适应滤波：使用加速度计（如 MPU6050）采集运动信号作为参考，LMS 自适应滤波器抵消运动分量。本项目可扩展加 MPU6050，I2C 地址 0x68。
  • 信号质量评估：计算 AC/DC 比值、过零率、自相关峰值比，作为信号质量指数 SQI，SQI < 阈值时不输出 HR。
  • 时域插值：对短暂丢点用前一次有效值填充，避免数值跳变引起 APP 报警误触发。

§36.6.3.2 调试建议

提示：调试 PPG 信号时，强烈建议先用串口把原始 IR 值打印到 Serial Plotter，观察波形是否呈典型"双峰"形态（主峰 + 重搏切迹）。波形正常后再做算法验证，可大幅缩短调试时间。

§36.7 扩展方向

§36.7.1 多参数融合

§36.7.1.1 扩展传感器方案

在 MAX30102 基础上叠加更多生理传感器，可显著提升监测价值：

  • 加速度计 + 陀螺仪（MPU6050/ICM-42670）：活动量统计、运动伪影抑制、跌倒检测。
  • 皮电传感器（GSR，模拟量接 ESP32 ADC）：情绪/压力水平评估。
  • 体温传感器（MLX90614 非接触）：连续体温监测。
  • 心电前端（ADS1292 / MAX30003）：ECG 与 PPG 联合测量，可实现脉搏波传导时间（PTT）法无创血压估算。

§36.7.1.2 融合设计考量

多参数融合需考虑传感器间时序对齐与功耗预算，建议使用 FreeRTOS 多任务调度。

§36.7.2 云端长期记录与分析

本项目 BLE 仅完成短距离上传，长期记录需结合 Wi-Fi 与云平台：

  • ESP32 启用 Wi-Fi，通过 MQTT 上报数据到 EMQX/阿里云 IoT 平台。
  • 云端做时序数据库存储（InfluxDB/TimescaleDB），按用户聚合。
  • 提供 REST API 供 APP 拉取历史曲线、日报、周报。
  • 可训练轻量 LSTM 模型做心律失常初筛（房颤、早搏），但模型推理建议放在云端，避免设备端算力瓶颈。

§36.7.3 跌倒检测

§36.7.3.1 检测流程

跌倒是老年人意外伤害的首要原因。融合加速度计后可实现跌倒检测：

  1. 检测三轴加速度合矢量是否超过 2.5 g（撞击瞬间）。
  2. 检测跌倒后 5 秒内姿态是否水平且无显著运动（无法起身）。
  3. 触发条件满足后通过 BLE/Wi-Fi 向监护人手机发送 SOS 推送。

§36.7.3.2 误报抑制

注意误报率控制：通过 SVM 或随机森林分类器对加速度模式做模式识别，区分跌倒与坐下、跳跃等动作。

本章小结

  • 智慧医疗是单片机的重要应用方向，PPG 是消费级心率血氧监测的核心物理原理。
  • MAX30102 集成双 LED + 光电二极管 + AFE + FIFO，通过 I2C 接口（地址 0x57）配置寄存器即可获取原始样本，简化了硬件设计。
  • 系统架构采用"传感-处理-呈现-通信"四层模型，I2C 总线共享降低布线复杂度，INT 中断驱动避免轮询。
  • 关键算法包括：直流/交流分离（滑动平均）、自相关法心率计算（抗噪强）、R 比值法 SpO2 计算（需标定）。
  • OLED 波形显示需采用局部刷新避免闪烁；BLE GATT 服务需合理拆分特征以适应订阅模型。
  • 运动伪影是 PPG 应用的核心难点，需结合机械设计、滤波、自适应算法、信号质量评估多管齐下。
  • 医疗设备具有严格的合规要求，教学项目需明确"消费级"定位，并在文档中如实标注测量精度与适用范围。

思考题与习题
