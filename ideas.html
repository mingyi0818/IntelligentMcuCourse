硬件组成

ESP32 主控 + 单路/多路继电器模块 + PZEM-004T 电能计量 + OLED 显示屏 + 物理按键 + 外壳。

实现方案
  • 方案 A（直连 MQTT）：ESP32 连接家庭路由器，订阅 MQTT 主题，手机 APP/微信小程序发布开断指令；PZEM-004T 经 UART 上报电压电流功率与累计电量。适合单点家庭使用，成本低、实现简单。
  • 方案 B（平台+本地保护）：在方案 A 基础上接入 OneNET/EMQX 云平台做用电画像，并加入本地过载保护（功率超阈值立即断继电器）与断网状态缓存，保证安全可靠与断网兜底。
软件流程

初始化 → 连 WiFi/MQTT → 循环读 PZEM 电量 → 监听 MQTT 指令与本地按键 → 控制继电器 → 过载判断 → 上报云端。

实现思路：ESP32 + 继电器 + 电能计量芯片，WiFi 连 MQTT 服务器（EMQX/OneNET），APP 远程通断并显示功率/电量，扩展定时、电量日/月报。

图 基于 STM32 的智能语音台灯系统架构图
硬件组成

STM32F407 + LD3320 语音识别模块 + PWM 调光 LED 驱动 + OLED +（可选）BH1750 环境光传感器 + 麦克风。

实现方案
  • 方案 A（离线命令词）：LD3320 通过 SPI 与 STM32 通信，预置"开灯/关灯/调亮/调暗"命令词，STM32 解析后输出 PWM 控制亮度。无需联网，响应快。
  • 方案 B（自动调光增强）：在方案 A 基础上接入 BH1750，实现"阅读/夜灯"模式自动亮度闭环，OLED 同步显示模式与亮度等级，体验更智能。
软件流程

初始化语音与 PWM → 等待语音指令 → 识别解析 → 更新 PWM 占空比 → 更新 OLED → 可选读环境光自适应。

实现思路：STM32F407 + LD3320 识别语音指令，输出 PWM 调光；OLED 显示状态，可扩展环境光传感器做自动调光。
