图 智能插座系统架构图
硬件组成

ESP32 主控 + 单路继电器模块 + PZEM-004T 电能计量 + OLED 显示屏 + 按键。

实现方案
  • 方案 A（ESP32 直连 MQTT）：ESP32 直接连接路由器，订阅 MQTT 主题，通过 APP/小程序发布开断指令；PZEM-004T 经 UART 上报电压电流功率累计电量。适合家庭单点使用，实现简单、成本低。
  • 方案 B（接入云平台+本地保护）：在方案 A 基础上增加本地过载保护逻辑（功率超过阈值立即断继电器），并缓存本地状态避免断网失联。适合需要安全可靠与断网兜底的场景。
软件流程

系统初始化 → 连接 WiFi/MQTT → 循环读取 PZEM 电量 → 监听 MQTT 指令与本地按键 → 控制继电器通断 → 判断过载保护 → 上报状态至云端。

实现思路：ESP32 + 继电器模块 + 电能计量芯片（如 PZEM-004T）。通过 WiFi 连接 MQTT 服务器（如 EMQX 或 OneNET），手机 APP（如 Blynk 或自研微信小程序）远程控制插座通断，并实时显示当前功率与累计电量。可扩展加入过载保护、定时开关、电量统计日 / 月报。
课程对接：第 18 章 USART + 第 19 章 ADC + 第 27 章 ESP32+Arduino。

图 智能语音台灯系统架构图
硬件组成

STM32F407 + LD3320 语音识别模块 + PWM 调光 LED + OLED +（可选）BH1750 环境光传感器。

实现方案
  • 方案 A（LD3320 离线命令词）：LD3320 通过 SPI 与 STM32 通信，预设"开灯/关灯/调亮/调暗"等命令词，STM32 解析结果后输出 PWM 控制亮度。无需联网，响应快。
  • 方案 B（LD3320 + 自动调光增强）：在方案 A 基础上接入 BH1750 环境光，实现"阅读模式/夜灯模式"自动亮度闭环调节，OLED 同步显示模式与亮度等级。
软件流程

初始化语音模块与 PWM → 等待语音指令 → 识别并解析命令词 → 更新 PWM 占空比 → 更新 OLED → 可选读环境光自适应调光。

实现思路：STM32F407 + LD3320 语音识别模块 + PWM 调光 LED + OLED 显示。LD3320 通过 SPI 与 STM32 通信，识别"开灯/关灯/调亮/调暗/读书模式/夜灯模式"等指令，STM32 输出 PWM 波形控制 LED 亮度。OLED 显示当前亮度等级与模式。可扩展加入环境光传感器（BH1750）实现自动调光。
课程对接：第 17 章 PWM + 第 20 章 SPI/I2C + 第 11 章 OLED。

图 智能晾衣控制系统架构图
硬件组成

STM32F407 + 步进电机（丝杠传动）+ 雨滴传感器 + 光敏传感器 + DHT11 + ESP8266 WiFi 模块。

实现方案
  • 方案 A（多传感器自动决策）：STM32 采集雨滴/光照/温湿度，按下雨或光照不足自动收回晾衣杆，天气转好再伸出；本地阈值判断为主，WiFi 仅作状态上报。可靠性高、断网可用。
  • 方案 B（FreeRTOS 多任务+云端联动）：用 FreeRTOS 将传感器采集、电机控制、WiFi 通信拆分为独立任务，云端支持手机远程手动控制与天气 API 联动决策。
软件流程

初始化外设与 FreeRTOS 任务 → 周期采集雨滴/光照/温湿度 → 决策判断伸出/收回 → 控制步进电机并限位 → 上传状态到云平台 → 响应远程指令。

实现思路：STM32F407 + 步进电机（丝杠传动）+ 雨滴传感器 + 光敏传感器 + DHT11 温湿度 + ESP8266 WiFi 模块。检测到下雨或光照不足时自动收回晾衣杆，天气转好再伸出。通过 WiFi 上传状态到云平台，支持手机远程控制。FreeRTOS 多任务：传感器采集、电机控制、WiFi 通信。
课程对接：第 17 章 PWM + 第 22 章 FreeRTOS + 第 27 章 ESP32。

图 基于 IoT 的智能家居系统架构图
硬件组成

ESP32 主节点 + 多个 STC89C52RC 子节点 + nRF24L01/ZigBee 无线模块 + 温湿度/烟雾/人体红外/门窗磁/插座/灯光等。

实现方案
  • 方案 A（ZigBee 组网）：CC2530 ZigBee 子节点负责各类传感器，ESP32 作为协调器汇聚数据后经 WiFi 上云，稳定性好、可扩展节点多。
  • 方案 B（nRF24L01 点对点组网）：成本更低的 nRF24L01 实现 STC89C52RC 子节点与 ESP32 主节点的星型组网，适合少量节点、控制成本的教学场景。
软件流程

主节点与子节点组网 → 子节点采集并上报 → 主节点汇聚解析 → 本地逻辑联动（烟雾报警/灯光控制）→ 上传云平台 → 响应 APP 与语音指令。

实现思路：ESP32 作为主节点 + 多个 STC89C52RC 作为子节点（ZigBee 或 nRF24L01 组网）。集成温湿度、烟雾、人体红外、门窗磁、智能插座、灯光控制等模块。ESP32 通过 WiFi 连接 Home Assistant 或自研云平台，支持语音控制（接入天猫精灵 / 小爱同学）。
课程对接：综合运用第 2 篇 STC + 第 3 篇 STM32 + 第 4 篇 ESP32。

图 智能门控安防系统架构图
硬件组成

STM32F407 + RC522 RFID + AS608 指纹 + 矩阵键盘 + 舵机 + 蜂鸣器 + ESP32-CAM（可选 K210 人脸识别）。

实现方案
  • 方案 A（多认证 + 报警联动）：刷卡/指纹/密码任一种验证通过后驱动舵机开门；连续 3 次验证失败触发蜂鸣器报警并让 ESP32-CAM 抓拍上传手机。
  • 方案 B（+人脸识别增强）：接入 K210 做人脸识别作为第四种认证方式，实现无感开门与更完善的访客记录。
软件流程

初始化认证外设 → 等待刷卡/指纹/密码输入 → 校验身份 → 成功驱动舵机开门并记录 → 失败累计次数，达 3 次触发报警抓拍 → 推送手机。

实现思路：STM32F407 + RC522 RFID 模块 + AS608 指纹模块 + 舵机（门锁）+ 摄像头（ESP32-CAM 抓拍）+ 蜂鸣器报警。多种认证方式：刷卡、指纹、密码。异常尝试 3 次触发报警，抓拍图片推送至手机。可扩展人脸识别（K210 模块）。
课程对接：第 33 章电子密码锁（已有）的升级版。

图 梅州金柚智能监测与采摘系统架构图
硬件组成

分布式柚园监测节点（STM32 + SX1278 LoRa + 土壤湿度 + 气象站）+ ESP32 网关 +（可选）机械臂采摘 + 视觉模块。

实现方案
  • 方案 A（LoRa 星型汇聚）：多个监测节点经 LoRa 将土壤与气象数据汇聚到 ESP32 网关，网关 WiFi 上云；结合金柚生长周期自动建议灌溉施肥方案。
  • 方案 B（+视觉辅助采摘）：扩展机械臂与摄像头，基于金柚颜色阈值判断成熟度，辅助半自动采摘。

STM32F407 + K210 AI 视觉 + 舵机分拣机构（4 分类）+ 超声波 + 语音播报。

实现方案
  • 方案 A（K210 图像分类）：K210 训练垃圾分类模型，识别可回收/有害/厨余/其他，舵机将垃圾拨入对应桶内。
  • 方案 B（+满载与语音反馈）：在方案 A 基础上增加超声波满载检测与语音播报，提升易用性。
软件流程

摄像头识别 → 分类判定 → 控制舵机分拣 → 检测满载 → 语音播报结果。

实现思路：STM32F407 + K210 AI 视觉模块 + 舵机分拣机构（4 分类：可回收/有害/厨余/其他）+ 超声波（满载检测）+ 语音播报。K210 训练垃圾分类模型，识别后舵机将垃圾拨入对应桶内。
课程对接：第 17 章 PWM（舵机）+ 第 18 章 USART（K210）。

图 人脸识别一体化集成系统架构图
硬件组成

STM32F407 + K210（人脸识别）+ 舵机门禁 + OLED + WiFi +（可选）MLX90614 测温。

实现方案
  • 方案 A（人脸识别考勤门禁）：人脸库烧入 K210，识别后开门并记录考勤，WiFi 上报。
  • 方案 B（+测温联动）：在方案 A 基础上增加 MLX90614 非接触测温，实现门禁+健康监测一体化。
软件流程

人脸采集识别 → 比对通过 → 驱动门禁 → 记录考勤/测温 → WiFi 上报。

实现思路：STM32F407 + K210（人脸检测+识别）+ 舵机门禁 + OLED + WiFi。人脸库烧入 K210，识别后开门并记录考勤。可扩展温度检测（MLX90614 非接触测温）。
课程对接：第 17 章 PWM + 第 18 章 USART + 第 33 章密码锁（已有）的人脸升级版。
