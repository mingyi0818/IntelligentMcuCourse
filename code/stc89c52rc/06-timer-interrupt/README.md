# 06-timer-interrupt 定时器中断

## 工程简介
本工程演示STC89C52RC定时器T0的中断应用。T0工作于方式1(16位定时)，每50ms产生一次中断，累计20次得到1秒，秒计数器通过串口9600波特率输出，体现中断驱动的精确定时编程思想。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| USB转TTL模块 | 1 | 用于串口通信 |
| 杜邦线 | 若干 | 连接串口 |

## 引脚连接表
| 单片机引脚 | 连接元件 | 说明 |
|-----------|---------|------|
| P3.0 | USB-TTL RXD | 串口接收 |
| P3.1 | USB-TTL TXD | 串口发送 |
| GND | USB-TTL GND | 公共地 |

## 定时器初值计算
```
晶振频率：11.0592 MHz
机器周期：12 / 11.0592MHz ≈ 1.085 us
定时50ms所需机器周期数：50000 / 1.085 ≈ 46083
T0方式1初值：65536 - 46083 = 19453 = 0x4BFD
∴ TH0 = 0x4B，TL0 = 0xFD
```

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 06-timer-interrupt`
3. 编译工程：`pio run`
4. 修改`platformio.ini`中的`upload_port`为实际COM口
5. 烧录：`pio run -t upload`
6. 打开串口助手，波特率9600，8N1

## 运行现象
- 串口输出"Timer Interrupt Demo Start"
- 每隔1秒串口输出当前秒数："Second: 1"、"Second: 2"...
- 时间精确，无累积误差(基于晶振)
