# 10-traffic-light 智能交通灯

## 工程简介
本工程是一个综合性的智能交通灯系统，集成了状态机、定时器中断、外部中断按键消抖、数码管动态扫描等技术。实现主干道与支路的红绿黄灯循环切换，2位数码管实时倒计时显示，行人按键请求可加快主干道绿灯切换为支路绿灯，是单片机课程的综合应用实验。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| LED | 6 | 红/黄/绿各2组 |
| 220Ω电阻 | 6 | LED限流 |
| 2位共阳数码管 | 1 | 倒计时显示 |
| 轻触按键 | 1 | 行人请求 |
| 10kΩ电阻 | 1 | 按键上拉 |
| 面包板+杜邦线 | 若干 | 连接电路 |

## 引脚连接表
| 单片机引脚 | 连接元件 | 说明 |
|-----------|---------|------|
| P2.0 | 主干道红LED | 主干道红灯 |
| P2.1 | 主干道黄LED | 主干道黄灯 |
| P2.2 | 主干道绿LED | 主干道绿灯 |
| P2.3 | 支路红LED | 支路红灯 |
| P2.4 | 支路黄LED | 支路黄灯 |
| P2.5 | 支路绿LED | 支路绿灯 |
| P2.6 | 数码管位选(十位) | 共阳公共端 |
| P2.7 | 数码管位选(个位) | 共阳公共端 |
| P0.0-P0.7 | 数码管段选a-g,dp | 段选数据 |
| P3.2 | 行人按键 → GND | INT0外部中断(带10kΩ上拉) |

## 状态机说明
| 状态 | 主干道 | 支路 | 时长 |
|------|--------|------|------|
| 0 | 绿灯 | 红灯 | 10秒 |
| 1 | 黄灯 | 红灯 | 3秒 |
| 2 | 红灯 | 绿灯 | 8秒 |
| 3 | 红灯 | 黄灯 | 3秒 |

行人按键(P3.2)：主干道绿灯时按下，剩余时间缩短为3秒，加快切换。

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 10-traffic-light`
3. 编译工程：`pio run`
4. 修改`platformio.ini`中的`upload_port`为实际COM口
5. 烧录：`pio run -t upload`

## 运行现象
- 主干道绿灯亮10秒，数码管倒计时10→0
- 主干道黄灯亮3秒
- 主干道红灯亮，支路绿灯亮8秒
- 支路黄灯亮3秒
- 循环往复
- 主干道绿灯期间按行人按键，倒计时缩短为3秒
