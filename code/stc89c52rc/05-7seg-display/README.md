# 05-7seg-display 数码管显示

## 工程简介
本工程演示4位共阴数码管的动态扫描显示技术。实现0-9999循环计数器，通过分时复用4位数码管，利用人眼视觉暂留效应实现4位数字同时稳定显示，是学习数码管驱动的核心实验。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| 4位共阴数码管 | 1 | 0.36/0.56英寸 |
| 220Ω电阻 | 8 | 段选限流 |
| 面包板+杜邦线 | 若干 | 连接电路 |

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 05-7seg-display`
3. 编译工程：`pio run`
4. 修改`platformio.ini`中的`upload_port`为实际COM口
5. 烧录：`pio run -t upload`

## 运行现象
- 数码管显示0000，每200ms加1
- 到9999后回到0000循环显示
- 4位数字稳定显示无闪烁
