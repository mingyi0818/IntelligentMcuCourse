# 07-uart 串口通信

## 工程简介
本工程演示STC89C52RC的串口通信技术。采用方式1(8位UART)、9600波特率，实现接收字符回显与接收计数功能。通过重定向`putchar`函数实现`printf`格式化输出到串口，是单片机调试与通信的基础实验。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| USB转TTL模块 | 1 | CH340/CP2102模块 |
| 杜邦线 | 3 | TX/RX/GND |

## 引脚连接表
| 单片机引脚 | 连接元件 | 说明 |
|-----------|---------|------|
| P3.0 (RXD) | USB-TTL TXD | 串口接收(交叉连接) |
| P3.1 (TXD) | USB-TTL RXD | 串口发送(交叉连接) |
| GND | USB-TTL GND | 公共地 |

## 波特率计算
```
晶振：11.0592 MHz
T1方式2(8位自动重装)，波特率 = (2^SMOD/32) × 定时器溢出率
SMOD=0(默认)，初值=0xFD(253)
溢出率 = 11059200/12/(256-253) = 307200
波特率 = 307200/32 = 9600 bps
```

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 07-uart`
3. 编译工程：`pio run`
4. 修改`platformio.ini`中的`upload_port`为实际COM口
5. 烧录：`pio run -t upload`
6. 打开串口助手，波特率9600，8N1，发送新行选择\r\n

## 运行现象
- 串口输出"UART Echo Demo Ready"等提示信息
- 在串口助手发送任意字符，单片机原样回显
- 发送回车键(0x0D)后，串口输出累计接收字符数
