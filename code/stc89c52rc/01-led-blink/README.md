# 01-led-blink LED闪烁

## 工程简介
本工程演示STC89C52RC单片机最基本的GPIO输出操作，通过P2.0引脚控制LED以1秒为周期闪烁，是学习单片机的"Hello World"实验。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| LED | 1 | 5mm红/绿色发光二极管 |
| 220Ω电阻 | 1 | 限流电阻 |
| 面包板+杜邦线 | 若干 | 连接电路 |

## 引脚连接表
| 单片机引脚 | 连接元件 | 说明 |
|-----------|---------|------|
| P2.0 | LED阳极(经220Ω电阻) | LED控制引脚 |
| GND | LED阴极 | 公共地 |

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 01-led-blink`
3. 编译工程：`pio run`
4. 连接USB转TTL模块到STC89C52RC的串口
5. 修改`platformio.ini`中的`upload_port`为实际COM口
6. 上电后烧录：`pio run -t upload`

## 运行现象
- LED以1秒为周期稳定闪烁（亮500ms，灭500ms）

## 扩展方向
- 修改延时参数改变闪烁频率
- 改用定时器中断实现更精确的定时
- 扩展为多LED不同频率闪烁
