# 03-button 按键控制

## 工程简介
本工程演示STC89C52RC的GPIO输入操作与按键消抖技术。4个独立按键分别控制4个LED的亮灭切换，采用10ms软件延时消抖，避免按键抖动导致的多次触发。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| LED | 4 | 5mm发光二极管 |
| 220Ω电阻 | 4 | LED限流 |
| 轻触按键 | 4 | 4脚轻触开关 |
| 10kΩ电阻 | 4 | 按键上拉电阻 |
| 面包板+杜邦线 | 若干 | 连接电路 |

## 引脚连接表
| 单片机引脚 | 连接元件 | 说明 |
|-----------|---------|------|
| P3.0 | 按键K1 → GND | 按键输入1（带10kΩ上拉到VCC） |
| P3.1 | 按键K2 → GND | 按键输入2 |
| P3.2 | 按键K3 → GND | 按键输入3 |
| P3.3 | 按键K4 → GND | 按键输入4 |
| P2.0 | LED1 + 220Ω | LED输出1 |
| P2.1 | LED2 + 220Ω | LED输出2 |
| P2.2 | LED3 + 220Ω | LED输出3 |
| P2.3 | LED4 + 220Ω | LED输出4 |

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 03-button`
3. 编译工程：`pio run`
4. 修改`platformio.ini`中的`upload_port`为实际COM口
5. 烧录：`pio run -t upload`

## 运行现象
- 上电后4个LED全灭
- 按K1切换LED1，按K2切换LED2，依此类推
- 每按一次按键，对应LED状态翻转一次
