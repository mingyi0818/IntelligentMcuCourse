# 02-flowing-led 流水灯

## 工程简介
本工程演示STC89C52RC并行I/O口操作与循环移位函数的使用。8个LED依次点亮形成流水效果，先左移后右移循环往复，是学习位运算与移位操作的典型实验。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| LED | 8 | 5mm发光二极管 |
| 220Ω电阻 | 8 | 限流电阻 |
| 面包板+杜邦线 | 若干 | 连接电路 |

## 引脚连接表
| 单片机引脚 | 连接元件 | 说明 |
|-----------|---------|------|
| P2.0 | LED1 + 220Ω | LED1控制 |
| P2.1 | LED2 + 220Ω | LED2控制 |
| P2.2 | LED3 + 220Ω | LED3控制 |
| P2.3 | LED4 + 220Ω | LED4控制 |
| P2.4 | LED5 + 220Ω | LED5控制 |
| P2.5 | LED6 + 220Ω | LED6控制 |
| P2.6 | LED7 + 220Ω | LED7控制 |
| P2.7 | LED8 + 220Ω | LED8控制 |
| GND | LED公共端 | 共阳接法 |

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 02-flowing-led`
3. 编译工程：`pio run`
4. 修改`platformio.ini`中的`upload_port`为实际COM口
5. 烧录：`pio run -t upload`

## 运行现象
- 8个LED先从P2.0到P2.7依次点亮（左移）
- 再从P2.7到P2.0依次点亮（右移）
- 形成往复流水效果，每个LED亮200ms
