# 04-matrix-keypad 矩阵键盘

## 工程简介
本工程演示4x4矩阵键盘的行列扫描法。16个按键以4行4列矩阵方式连接，通过分行扫描、逐列检测的方式识别按键，并通过串口9600波特率输出按键值，节省I/O口资源。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| 4x4矩阵键盘模块 | 1 | 16键薄膜/PCB键盘 |
| USB转TTL模块 | 1 | 用于串口通信 |
| 面包板+杜邦线 | 若干 | 连接电路 |

| P1.2 | 矩阵键盘ROW3 | 行线3 |
| P1.3 | 矩阵键盘ROW4 | 行线4 |
| P1.4 | 矩阵键盘COL1 | 列线1 |
| P1.5 | 矩阵键盘COL2 | 列线2 |
| P1.6 | 矩阵键盘COL3 | 列线3 |
| P1.7 | 矩阵键盘COL4 | 列线4 |

| P3.1 | USB-TTL TXD | 串口发送 |

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 04-matrix-keypad`
3. 编译工程：`pio run`
4. 修改`platformio.ini`中的`upload_port`为实际COM口
5. 烧录：`pio run -t upload`
6. 打开串口助手，波特率9600，8N1

## 运行现象
- 上电后串口输出"Matrix Keypad Ready"
- 按下矩阵键盘任意键，串口输出对应字符(0-9, A-F)
- 串口助手中可实时显示按键值
