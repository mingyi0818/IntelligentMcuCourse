# 08-lcd1602 LCD1602显示

## 工程简介
本工程演示LCD1602字符液晶的驱动技术。包含完整的写指令、写数据、初始化、定位、字符串显示函数，第1行显示"Hello MCU!"，第2行通过定时器中断累计显示运行时间(秒)，是学习字符型LCD驱动与时序控制的核心实验。

## 硬件清单
| 元件 | 数量 | 说明 |
|------|------|------|
| STC89C52RC最小系统板 | 1 | 11.0592MHz晶振 |
| LCD1602液晶模块 | 1 | 16x2字符型 |
| 10kΩ电位器 | 1 | LCD对比度调节 |
| 面包板+杜邦线 | 若干 | 连接电路 |

## 引脚连接表
| 单片机引脚 | LCD1602引脚 | 说明 |
|-----------|------------|------|
| P0.0 | D0 | 数据位0 |
| P0.1 | D1 | 数据位1 |
| P0.2 | D2 | 数据位2 |
| P0.3 | D3 | 数据位3 |
| P0.4 | D4 | 数据位4 |
| P0.5 | D5 | 数据位5 |
| P0.6 | D6 | 数据位6 |
| P0.7 | D7 | 数据位7 |
| P2.5 | RS | 寄存器选择 |
| P2.6 | RW | 读写选择 |
| P2.7 | E | 使能信号 |
| VCC | VCC/BLA | 电源+背光正极 |
| GND | GND/BLK | 公共地+背光负极 |
| - | V0 | 接电位器中点调对比度 |

## 编译烧录方法
1. 安装PlatformIO Core：`pip install platformio`
2. 进入工程目录：`cd 08-lcd1602`
3. 编译工程：`pio run`
4. 修改`platformio.ini`中的`upload_port`为实际COM口
5. 烧录：`pio run -t upload`
6. 调节电位器使LCD显示清晰

## 运行现象
- LCD第1行显示"Hello MCU!"
- LCD第2行显示"Time: X s"，X为运行秒数，每秒+1
- 字符显示稳定清晰
